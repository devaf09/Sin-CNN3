# Sin-CNN3

sin・cos の波に情報を載せて入れ、フーリエ変換で読み出し、重ね書きして覚える仕組みを、**小さなモデルから作り直して「なぜそうなるか」を理解する**研究の記録です。

> **開発中です（版 0.0.0）。** いまは最初の段（M0: FFT などのライブラリと計算の約束を、手計算・素朴な式と突き合わせて確かめる）を始めたところです。まだ使える部品はありません。

（しくみの図は、最初の実験ができたら docs/images/ に置いてここに載せます）

## これは何？

音や光の波は、いくつもの波を重ねても、あとで「どの高さの音が・どれだけの強さで入っていたか」を分けて取り出せます（フーリエ変換）。
この性質を使えば、数や記号を波に載せて運び、1 本の信号に重ねて覚えさせることができそうです。

前のプロジェクトとの関係:
- [Sin-CNN2](https://github.com/devaf09/Sin-CNN2): 1 次元の波（SinWave）の干渉と回折だけで学ぶ学習器
- SN2-Parts-2D: それを 2 次元に広げた部品。光の記憶（4f 系の板への重ね書き）で、学習なしの融合・忘却・確信度は出たが、崩れた鍵から思い出す力と容量でデジタルの辞書に負けた
- Sin-CNN3（ここ）: 大きな構成から始めず、数個〜数十個の sin・cos、長さ 8〜64 の信号から、1 つずつ確かめて積み上げる

## 分かったことの一覧

| 分かったこと | 確かめた実験 |
|---|---|
| numpy と torch の FFT は、自作の素朴な和・式の予想と一致する（差 1e-14 以下） | 実験01・02 |
| norm は割る場所の約束（1・1/√N・1/N）だけ。"ortho" だけがエネルギーを保つ | 実験02 |
| 1 本の周波数に振幅と位相の 2 つの数を載せ、そのまま読み出せる | 実験02 |
| 半端な周波数は全番号に漏れる。窓関数で減るが山は太る | 実験03 |
