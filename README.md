# Sin-CNN3

> **いまの状態を一目で: [docs/overview.md](docs/overview.md)**（しくみの図・できたこと・最近の結果・まだできないこと）
>
> **既存の AI やシステムにない成果と、そのしくみ: [docs/unique_results.md](docs/unique_results.md)**

sin・cos の波に情報を載せて入れ、フーリエ変換で読み出し、重ね書きして覚える仕組みを、**小さなモデルから作り直して「なぜそうなるか」を理解する**研究の記録です。

> **2026-11-02 時点: 実験 01〜121 まで。** 会話ボット「テストボット02」の部品は、言結い（Project_Kotoyui）へ引き継ぎ済みです（[引き継ぎ書](docs/handover_kotoyui_20261102.md)）。ここ Sin-CNN3 には、語板・構造の育て方（穴埋め・往復・区切り）・ホログラフィックな物語の光の研究が残っています。まだ配れる部品（sincnn3.py）はありません。
>
> まとめ: [初日（実験01〜26）](docs/summary_20261027.md)・[一時まとめ（実験55〜77）](docs/summary_20261031.md)・[引き継ぎ書（実験99〜121）](docs/handover_kotoyui_20261102.md)。文書の一覧は [docs/README.md](docs/README.md)。

## これは何？

音や光の波は、いくつもの波を重ねても、あとで「どの高さの音が・どれだけの強さで入っていたか」を分けて取り出せます（フーリエ変換）。
この性質を使えば、数や記号を波に載せて運び、1 本の信号に重ねて覚えさせることができそうです。

前のプロジェクトとの関係:
- [Sin-CNN2](https://github.com/devaf09/Sin-CNN2): 1 次元の波（SinWave）の干渉と回折だけで学ぶ学習器
- SN2-Parts-2D: それを 2 次元に広げた部品。光の記憶（4f 系の板への重ね書き）で、学習なしの融合・忘却・確信度は出たが、崩れた鍵から思い出す力と容量でデジタルの辞書に負けた
- Sin-CNN3（ここ）: 大きな構成から始めず、数個〜数十個の sin・cos、長さ 8〜64 の信号から、1 つずつ確かめて積み上げる

## このプロジェクトならではの機能（2026-10-27 時点。しくみつきの紹介と、その後の成果は [docs/unique_results.md](docs/unique_results.md)。設計の工夫の一覧は [docs/plan_large_scale.md](docs/plan_large_scale.md) の 5 章）

器の形（位相の板 + 回折を何枚も）は回折の深層ネットワーク（D²NN、2018）と、照らし方で働きを切り替える考え方は回折ネットワークの多重化（2023〜2026）と同じ（[docs/prior_art.md](docs/prior_art.md)）。そのうえで、ここで作って確かめた機能:

| 機能 | 何ができるか | 実験 |
|---|---|---|
| 観点周波数の逆引き | 値の光を逆向きに通すだけで「その値を持つ物」が光る（逆向きの明るさ = 順向きの明るさ） | 21 |
| 手がかりの掛け算による推し量り | 「丸い赤い実をむしゃむしゃ、酸っぱい」→ トマト 70%・イチゴ 29%。デジタルの推し量りと差 1 点以内、4 ビットの粗さでも崩れない | 21・24・25 |
| 2 つの意味を持つ言葉 | 重ね合わせで両方の意味を持ち、手がかりで 1 つに決める（リンゴ: 果物 / 人） | 26 |
| 知らない意味に気づき、書き込む | 合わない文は光が 75〜340 倍暗い（驚き）。仲間を当てて新しい意味を書き込むと、仲間の属性を受け継ぐ | 27 |
| 拡散と「なし」の使い分け | 存在しない属性を「分からない」と「ない」で区別して推し量りの性格を変える | 23 |
| 関係をつなげる | 出力の光をそのまま次の入力にして何段もたどる。枝分かれは同時に進む | 17 |
| 絞る部品・広げる部品 | 測って出し直す（2 乗）で強い候補だけ残す、リミッタで候補を広げる。どちらも光の部品 | 22 |
| 単語ごとの格子 | 格子そのものが単語の意味（1 単語 1 KB）。入口は共通の「何か」の光だけ。融合は格子を並べて光を足す | 31 |
| 単語の格子を関数として使う | 道具を要素の光で入れると結果が出る。見せていない道具（圧力鍋 = 圧力 + 熱）でも要素から推し量り、逆向きに「ジュースにするには圧力・回転」が分かる | 32 |
| 曲がる処理で表計算を越える | カー効果で「どちらか片方だけ」を 100%（線形は 75% が上限） | 14 |

## 分かったことの一覧

| 分かったこと | 確かめた実験 |
|---|---|
| numpy と torch の FFT は、自作の素朴な和・式の予想と一致する（差 1e-14 以下） | 実験01・02 |
| norm は割る場所の約束（1・1/√N・1/N）だけ。"ortho" だけがエネルギーを保つ | 実験02 |
| 1 本の周波数に振幅と位相の 2 つの数を載せ、そのまま読み出せる | 実験02 |
| 半端な周波数は全番号に漏れる。窓関数で減るが山は太る | 実験03 |
| 周波数の格子の板に波を当てると、同じ周波数の区画だけが光る。位相を読むには cos と sin の板が両方要る | 実験04 |
| 観点周波数（縦の周波数のずらしで属性を選ぶ）で物の属性を覚え、値の光を逆向きに通して掛け算すると、「丸い赤い実をむしゃむしゃ食べた、酸っぱかった」→ トマト、と推し量れる | 実験21 |
| 知らない意味の文（リンゴは楽しそうに手を振った）は、光をたどった明るさが 75〜340 倍暗くなって気づける。属性を仲間に持たせると、手がかりから「人間の何か」と当て、新しい意味として書き込める | 実験27 |
| 2 つの意味を持つ言葉（果物のリンゴと人物のリンゴさん）を重ね合わせで持ち、手がかりの掛け算で 1 つに決められる | 実験26 |
| 明るさで曲がる処理（カー効果）を入れた光の格子は、表計算（線形）では解けない「どちらか片方だけ」を 100% 解く（曲がる処理なしは 75% が上限） | 実験14 |
| 記号を整数の周波数の波で表すと、光の格子で「A → B, C, D」と、縦の周波数を 1 ずらしたときの「A → G, H」を同時に持てる（関係性概念、持ち主の案） | 実験15・16 |
| 波どうしを掛けると、周波数が差と和にずれる（周波数の側ではぐるっと回る畳み込み） | 実験05 |
| 鍵と値を掛け算で結んで重ね書きする記憶は、でたらめな鍵どうしの小さな重なりが組の数だけたまって崩れる。半分当たる組の数は約 N/(2·ln 候補の数) で、式と実験が一致する | 実験08 |
| 長さ N の信号には N 個の数が重ねて入り、雑音がなければ全部読める。雑音の誤差は本数によらない。光の量に上限があると、本数を増やすほど相対誤差が √本数 倍に増える | 実験06 |

## ここまでの結果

| 目標 | 状況 |
|---|---|
| M0: ライブラリと計算の約束の確認 | 8 項目を確認、食い違いなし（実験01〜03・07・10）。残り: rfft・精度・回折の標本化 |
