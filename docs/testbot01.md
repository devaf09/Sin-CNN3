# テストボット01 — 光の語板で連想して、決まった型の文で返す小さな会話ボット

2026-10-29 作成。持ち主の依頼「現状の学習結果から会話ボットを組み立てられる？ 次の試験で使いたい、テストボット01 として」。
本体: [src/testbot01.py](../src/testbot01.py)（コメント多め）。語板: 実験69（experiments/exp69_testbot_model.py）で作った、非公開フォルダの models/testbot01.pt。

## 1. 何ができるか

| 入力の形 | ボットがすること | 使っている部品 |
|---|---|---|
| 名詞だけ（「ラーメンが好きです」「コーヒー」） | その名詞の、いちばん自信のある使われ方を話題にする（ラーメン → 食べる） | 語板の順引き（学び 55・59） |
| 名詞 + を/が/で/に + 動詞（「昨日ラーメンを食べた」） | よくある組み合わせなら、動詞の語板で「どこで」をたどって聞き返す（食べる → 家で） | 名詞 → 動詞 → 名詞のたどり（学び 56）、逆引きに語の多さを掛ける（学び 59・61） |
| 珍しい組み合わせ（「パソコンを食べた」） | 驚いて、ふつうの使い方を教える（パソコン → 使う） | 驚き = 光が暗い（学び 27） |
| 否定（「本を読まない」） | 残りの光から、代わりによくある使い方を返す（本 → 買う） | 「〜ではない」= 1 − p（学び 53） |
| 知らない名詞（「ぽんぽこりんが来た」） | 「知らない言葉です、教えて」と聞き返す | 知らない物に気づく（学び 51） |
| 自信が低いとき | 「たぶんですが、」を付ける | 光の偏り = 確信度（学び 62） |

## 2. 使い方

```
python src/testbot01.py          # 対話（終わるときは空行）
```

```python
import sys; sys.path.insert(0, "src")
from testbot01 import TestBot01
bot = TestBot01()                       # 語板を読む（非公開フォルダの models/testbot01.pt）
print(bot.reply("ラーメンが好きです"))
print(bot.explain("ラーメンを食べた"))  # 中で何を考えたか（見つけた語・組、語板の上位の値と割合）
```

## 3. 試した会話（2026-10-29）

| あなた | ボット |
|---|---|
| ラーメンが好きです | ラーメンといえば、食べることが多いですよね。最近食べる機会はありましたか？ |
| 昨日ラーメンを食べた | いいですね！ラーメンを食べるんですね。家で食べることが多いんですか？ |
| 服を買いに行った | いいですね！服を買うんですね。スーパーで買うことが多いんですか？ |
| お茶を飲んだ | いいですね！お茶を飲むんですね。一人で飲むことが多いんですか？ |
| パソコンを食べた | パソコンを食べるって、ちょっと珍しいですね！ふつうは使うことが多いみたいです。 |
| 本を読まない | そうなんですね。本は、買うことのほうが多いみたいですよ。 |
| ぽんぽこりんが来た | 「ぽんぽこりん」は、まだ知らない言葉です。どんなものか教えてもらえますか？ |
| 猫が好き | たぶんですが、可愛い猫、いいですね。 |
| 映画を見に行った | いいですね！映画を見るんですね。目で見ることが多いんですか？（← 不自然） |
| 雪 | たぶんですが、雪で遊ぶことが多いんですか？ |
| おはようございます | なるほど。もう少し詳しく聞かせてください。（← 名詞がないと何も言えない） |

`explain("ラーメンを食べた")` の中身（語板「ラーメン」の明るさ）: どんな → 美味しい 0.34・好き 0.05、を → 食べる 0.54・作る 0.11、で → 済む 0.40・言う 0.20 …

語板の当たり（実験69、会話の確かめ用の交差エントロピー）: 名詞 5000 語 2.40（表 2.36）、動詞 1000 語 1.24（表 1.19）。値に届く光 94〜96%。

## 4. 限界（テストで気をつけるところ）

- **返事はすべて決まった型**（10 種類ほど）。文を自由には作れない。
- **前の会話を覚えていない**（1 回ごとに独立）。
- 名詞と「名詞 + 助詞 + 動詞」しか見ていない。あいさつ・気持ち（「苦手」「嬉しい」）・時（昨日・明日）・副詞は読んでいない。
  「料理を作るのが苦手」にも「いいですね！」と返してしまう。
- 「どこで」のたどりが不自然なことがある（映画 → 見る → 目で、雨 → 降る → 勢いで）。動詞の語板の「で」が、場所と手段・様子を区別していないため。
- 動詞の活用は作れない（辞書の形のまま「〜こと」「〜んですね」に入れている）。
- 材料に Web 小説（研究のみ）を含むので、このボットと語板は公開しない。

## 5. 文を作るために、あと必要な能力（持ち主の問いへの答え）

いまの語板は「語の使われ方の辞書」。文を作るには、少なくとも次が要る。

| 必要な能力 | 中身 | 今どこまで | 次の一歩 |
|---|---|---|---|
| ① 語順（次の語を選ぶ） | 前の語から、次に来る語を確率で選ぶ | 2 段の器で 2-gram 越え（27%）、3-gram（34%）には届かず（実験38・54） | 語板を入口にした次の語の予測。位置の入れ方 |
| ② 文の骨組み（文法・活用・助詞） | 動詞の活用（食べる → 食べました）、助詞の選び方、文の終わり方 | なし（型の文で代用） | 活用を「語板の観点」として学ぶ（語幹 × 活用形）。形態素解析器の情報を使う |
| ③ 会話の流れ（文脈の記憶） | 前の発話・話題を覚え、それに合わせて話す | 注意機構の部品（実験49、番地に並べる）はある。ボットには未接続 | 発話ごとの行板を番地に並べ、話題を引き出す（実験70 の連想と同じ仕組み） |
| ④ 何を言うか（意図・気持ちの読み取り） | 質問か、共感か、提案か。「苦手」「嬉しい」の読み取り | なし | 文末・形容詞の観点を足す。f2 のモード（学び 41）で返事の型を切り替える |
| ⑤ 観点の広がり | 主語の省略、時、副詞、動詞どうしの関係（「〜しに行く」） | 名詞 + 助詞 + 動詞の 5 観点だけ | 観点を増やす（属性の重要さで選ぶ、設計の工夫） |
| ⑥ 評価 | 返事が自然か・役に立つかを測る | なし | 確かめ用の会話で、返事の候補の当たり（○○ 当て）や、人の評価 |

**現実的な近道（テストボット02 の案）**: 一から文を作る前に、**会話の材料から「返事の候補の文」を探し、語板で並べ替える**形（検索 + 並べ替え）。
文の自然さは本物の会話が持っていて、語板は「入力の文と、候補の文の語の使われ方が合っているか」を光で比べる役（自覚の確信度で「わかりません」も言える）。
そのあと、① 次の語の予測と ② 骨組みを語板で育てて、少しずつ自分で作る割合を増やす。
