# ライブラリと計算の約束の確認表（M0）

前のプロジェクト（SN2-Parts-2D の sn2_parts_2d.py 0.11.0、Sin-CNN2 の sinwave_minimal.py 1.3.0）で使った計算を、小さな例で 1 つずつ確かめる。
確かめ方は「手計算・式・別の方法（numpy と torch、FFT と素朴な和）」のどれかと必ず突き合わせる。各行の説明は docs/lessons/ の該当ノートにある。

結果の記号: ✓ 期待どおり / ✗ 期待と違う / △ 条件つき / − まだ

| 関数・計算 | 期待すること | 確かめ方 | 結果 | 前のプロジェクトでの使い方 | 問題の有無 |
|---|---|---|---|---|---|
| 素朴な離散フーリエ変換（自作の基準） | X[k] = Σ x[n]·e^(−2πi·kn/N) を式どおりに計算する | 手計算（N = 4, 8） | − | （使っていない） | − |
| fft / ifft（numpy・torch） | 素朴な和と一致し、ifft(fft(x)) = x | 素朴な和との差の最大値 | − | | − |
| norm の "backward"・"ortho"・"forward" | 大きさの付き方が 1・1/√N・1/N で入れ替わる | 3 通りを並べる | − | | − |
| パーセバルの等式 | 波の側と周波数の側でエネルギーが同じ（norm に応じた係数つき） | 両側の 2 乗和 | − | | − |
| fftfreq・fftshift | 0 番が直流、後半が負の周波数。shift で直流が中央 | 番号の表 | − | | − |
| sin・cos の出る場所 | cos は実部に N/2 ずつ、sin は虚部に ∓N/2（符号に注意） | 手計算と並べる | − | | − |
| rfft / irfft | 半分（N/2 + 1 個）だけ返す。長さ n を渡さないと奇数長で戻らない | 奇数・偶数の長さで往復 | − | | − |
| 周波数の漏れと窓関数 | 割り切れない周波数は周りに漏れる。窓で漏れが減る | 式（ディリクレ核）と並べる | − | | − |
