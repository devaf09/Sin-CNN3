# ライブラリと計算の約束の確認表（M0）

前のプロジェクト（SN2-Parts-2D の sn2_parts_2d.py 0.11.0、Sin-CNN2 の sinwave_minimal.py 1.3.0）で使った計算を、小さな例で 1 つずつ確かめる。
確かめ方は「手計算・式・別の方法（numpy と torch、FFT と素朴な和）」のどれかと必ず突き合わせる。各行の説明は docs/lessons/ の該当ノートにある。

結果の記号: ✓ 期待どおり / ✗ 期待と違う / △ 条件つき / − まだ

| 関数・計算 | 期待すること | 確かめ方 | 結果 | 前のプロジェクトでの使い方 | 問題の有無 |
|---|---|---|---|---|---|
| 素朴な離散フーリエ変換（自作の基準） | X[k] = Σ x[n]·e^(−2πi·kn/N) を式どおりに計算する | 手計算（N = 8 の cos、実験01） | ✓ 式の予想と差 4.6e-15 | （使っていない） | なし |
| fft / ifft（numpy・torch） | 素朴な和と一致し、ifft(fft(x)) = x | 素朴な和との差（N = 8、実験01・02） | ✓ fft は差 1e-14 以下。同じ norm の ifft で往復の差 4e-16 以下 | 回折は backward の行き帰り、レンズ・4f 系は ortho の行き帰り（読んだ範囲。動かしての確認はまだ） | なし（この範囲） |
| norm の "backward"・"ortho"・"forward" | 大きさの付き方が 1・1/√N・1/N で入れ替わる | 3 通りを並べる（実験02） | ✓ 1・1/√N・1/N。違う norm で往復すると √N・N 倍ずれる | 上と同じ。それぞれの中ではそろっている | なし（この範囲） |
