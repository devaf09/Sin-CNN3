# 2026-10-27 のまとめ（実験01〜19）

Sin-CNN3 の初日に分かったことを、持ち主が家でゆっくり読めるように 1 枚にまとめた。数字の正本は NOTES.md、一歩ずつの説明は docs/lessons/、疑問と注意点は docs/tsukkomi.md。

## 一言でいうと

- **前のプロジェクトの計算の約束（FFT など）に誤りは見つからなかった**。記憶が崩れた理由は計算の誤りではなく、「でたらめな鍵どうしの小さな重なり」という結び方そのものの限界で、式で説明できた。
- **持ち主の周波数格子の学習器は、器の形（列の間の距離）を直すと学べる**。曲がる処理なしでは「表 1 枚」と同じだが、**カー効果（明るいほど遅れる）を入れると、表計算では解けない課題を 100% 解いた**。
- **関係性概念（持ち主の依頼）は、記号を「混ざらない周波数の光」で表すと、縦の周波数を 1 ずらすだけで別の関係に切り替わった**。出力の光をそのまま次の入力にして、関係を何段もたどれた。

## 段階ごとの結果

### M0: 計算の約束の確認（実験01〜03・07・10）

| 確かめたこと | 結果 |
|---|---|
| numpy・torch の FFT と、自作の素朴な和 | 一致（差 10⁻¹⁴ 以下） |
| norm の 3 通り・往復・エネルギー | 約束どおり。"ortho" だけがエネルギーを保つ |
| sin・cos の出る場所、振幅と位相 | 1 本の周波数に振幅と位相の 2 つの数が載り、そのまま読める |
| 半端な周波数 | 全部の番号に漏れる（窓関数で減る） |
| ぐるっと回る計算（ゼロ詰め） | 誤りではなく約束。ただし実際の装置とは雑音の出る場所が違う |
| 複素数の勾配 | torch は「実部の勾配 + i × 虚部の勾配」で、式どおり |

残り: rfft、32 ビットと GPU の精度、回折の標本化の条件。

### なぜ情報を載せられ、なぜ記憶が崩れるか（実験04〜06・08）

- 違う周波数の波は、掛けて足すと打ち消し合う。だから**長さ N の信号には N 個の数が混ざらずに入る**（実験06）。周波数の格子の板に波を当てると、同じ周波数の区画だけが光る（実験04、持ち主の案）。
- 波どうしを掛けると、周波数が差と和にずれる。これが「処理」の材料になる（実験05）。
- 鍵と値を掛け算で結んで重ね書きする記憶は、でたらめな鍵どうしが少しずつ重なり、その重なりが組の数だけ雑音としてたまって崩れる。**半分当たる組の数 ≈ N / (2·ln 候補の数)**。4 つの作り方（前のプロジェクトの形を含む）で、式と実験が数点以内で一致（実験08）。

### 持ち主の周波数格子の学習器（実験09〜14・19）

| 実験 | 分かったこと |
|---|---|
| 09 | 曲がる処理なしでは、100 列を通しても全体は「表 1 枚」と同じ（重ね合わせの差 10⁻⁶）。カー効果では光の点が自分で通り道を作る |
| 11 | 学習すれば「入力 → 答え」を覚える。覚えられる数は学習する数で決まる。縦横とも sin と cos にすると増える。学習率は小さめに |

| 19 | カー効果を切ると 100% → 76%。入れる光が増えると行き先が 窓 0 → 1 → 0 と回る |

### 関係性概念（実験15〜18、持ち主の依頼）

| 実験 | 分かったこと |
|---|---|
| 15 | 第 1 段階（A → B, C, D など）は 100%。記号を細い光の点で表すと、縦の周波数を少しずらしても入力がほとんど変わらず（重なり 0.999）、第 2 段階は切り替わらない（光の量を保つ器は重なりを保つため） |
| **16** | **記号を整数の周波数の波で表すと、1 ずらすだけで入力の重なりが 0 になり、A → B, C, D と A → G, H を切り替えられた（3 seed とも 100%）** |
| **17** | **出力の光をそのまま次の入力にして、関係を 5 段たどれた。枝分かれは重ね合わせのまま同時に進む** |
| 18 | 記号 24 × 文脈 4 の 96 組を 1 つの器に入れても、ほぼ全部当たる。崩れ方は「答えに集まる光が薄くなる」形 |

## 持ち主の疑問への、いまの答え

| 疑問 | いまの答え |
|---|---|
| 前のプロジェクトのライブラリや計算の約束が合っていなかったのでは | 確かめた範囲では合っていた。記憶の崩れは結び方の限界（実験08） |
| 勾配降下法は光式（周波数式）に合っていないのでは | 勾配の計算は正しい（実験10）。失敗の主な原因は器の形だった（実験13）。ただし位相は一周するので学習率に敏感で、曲がる処理なしは谷に落ちやすい。勾配降下以外との比べはまだ |
| 曲がりを考えると角速度を乱す必要があるか | 曲がる処理は自分で新しい周波数（差と和）を作る。整数の周波数どうしの差と和はまた整数なので、直交を保ったままでも働くはず（実験05）。直交を保つことは関係性概念でそのまま効いた（実験16） |
| 記憶と処理を同時にできるか | 関係性概念の器は、関係を覚える（記憶）と、たどる・切り替える（処理）を同じ光の通り道でしている（実験16〜18）。カー効果で表計算を越える処理もできた（実験14）。両方を 1 つの器で、はまだ |
