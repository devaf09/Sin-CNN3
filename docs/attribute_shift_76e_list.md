- **属性の流れ** = 後ろの行 D の上位 3 属性から属性樹を共通の枝まで逆に登り、前の行 B の共通の枝まで登りながら拾った属性（先頭 6）。
- **流れに対応した語板** = 流れの属性ごとに、その属性がいちばん持ち上がる語板（よく出る語を少し優先、B・D の語は除く）。

- **一致率** = 間の行 C の名詞（B・D に出ないもの）のうち、流れの語板とつながりの語板のどちらかに入った割合。
