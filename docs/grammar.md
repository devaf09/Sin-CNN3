# 文法解析・組立

持ち主の方針（2026-10-31）: 文は「骨組みは文法（木）で組み立て、中身と選び方は確率（語板）で」。このページに、文法解析と組み立ての決まりと、使う属性をまとめていく。
関連: [計画 8 節](plan_large_scale.md)、[データ構造](data_structures.md) 6 節（辞書類）、[一時まとめ](summary_20261031.md)。

## 1. 属性：品詞一覧（観点周波数「品詞」）

持ち主: 「品詞体系図で、数に上限があるものは属性一覧を作る。名詞のように上限がないものは『属性焦点：名詞』で終わり。助詞は上限があるので全部入れる。まずは最大数を決め、計算の負担が出たら減らす」。

- 体系は Sudachi（UniDic と同じ品詞体系）の大分類・中分類。学校文法の「形容動詞」は、Sudachi では **形状詞**（静か・綺麗 の語幹）＋助動詞「だ」に分かれる。
- 数は材料（会話 669 万語・青空文庫 300 作品 447 万語・Web 小説 3000 話 507 万語、計 1,623 万語）で数えた出現の割合（tools/pos_freq.py、非公開フォルダの data/dict/pos_freq.json）。
- 辞書（SudachiDict）にある語の数と、材料の出現の 99.9% を占める語の数を並べた。**最大数 = 99.9% の語の数**とし、それより珍しい語（古語・方言など）は品詞ごとの「その他」に入れる。

### 1.3 最大数と器

- **最大数 = 上限のない品詞 26 ＋ 上限のある品詞 255 ＋ 品詞ごとの「その他」10 = 291**。
- 1 つの観点に置ける値は、器の縦 − 10（出口は周波数 10 から）。縦 128 なら 118、縦 256 なら 246、縦 512 なら 502。
- 案 A（最大のまま）: 品詞の観点だけ縦 512 の器にする（291 値が入る）。
- 案 B（器を変えない）: 観点を 2 本に分ける。「品詞」= 上限のない品詞 26 ＋ 上限のある品詞の中分類 10 ＝ 36 値、「機能語」= 上限のある品詞の語。縦 128 なら 99% の語（155）も入らないので、機能語の観点は縦 256 にする。
- 案 C（減らす）: 99% の語にして、代名詞（指示・人称で数が多い）と連体詞は品詞の名前だけにする → 26 ＋ 助詞・助動詞・接続詞の 99% 88 ＋ 代名詞・連体詞 2 ＋ その他 = 約 117（縦 128 に入る）。

### 2.5 人称でない代名詞（指示・疑問）

其れ（それ）・此れ（これ）・彼れ（あれ）・そこ・此処（ここ）・彼処（あそこ）・何・どこ・いつ・どれ・どちら・どっち など。物・場所・方向・時を指す（こそあど）。人称の観点では「人称なし」。

### 2.6 属性 3 つへの関連付け（案）

- 観点「人称」を 1 本足し、値を **一人称・二人称・三人称**（＋ 人称なし・揺れ用のその他）にする。語板の出口は割合なので、「此方」は 一人称 0.2・人称なし 0.8 のように揺れのまま持てる。
- 品詞の観点（D 案）と同じく周波数の枝として足すので、ほかの観点の逆引きには影響しない。
- 言結いでは、話し手が変わると一人称・二人称が入れ替わる（A の「私」= B から見た「あなた」）。人称の観点を持っておけば、話し手の入れ替えを光の値の入れ替え（一人称 ↔ 二人称の出口の交換）で表せる。

## 3. 品詞の学習のしかた（実験78 で試した）

結果: [実験78 の一覧](pos_views_78.md)。D 案（観点 1 = 大分類、観点 2〜8 = 中分類）で 5 万語、大分類の上位 1 の当たり 96.6%、揺れ（又 = 副詞 0.54・接続詞 0.44）も割合のまま残り、最初の枝からの逆引きで品詞の語が並んだ。

以下は、はじめに書いた案:

- 見出し表（190 万語）の各語に、材料の中で実際に出た品詞の割合を数える（が の 72% は格助詞、14% は接続助詞…）。辞書の品詞だけなら決まっているので、材料で割合を付けるのが学ぶ意味のある所。
- 語板（観点「品詞」）をこの割合に学ばせる。新しい語が出たら、前後の語の品詞から、まず品詞を推して語板を作る（持ち主の案）。
- 文法解析では、文の各語の品詞の割合を並べたものが、係り方の候補を並べる出発点になる。

## 4. 文法と語板のつなぎ方（持ち主の流れ 2026-10-31）

持ち主: 「単語 → 語板 → 各属性に文法解析の属性重みを足す → 属性から語板を逆引き → 単語。例えば主語 + 述語の関係」。

- 観点がそのまま文法の役割: が = 主語として、を = 目的語として、どんな = 修飾、の前・の後 = 「A の B」。主語 + 述語 = が の観点の光を通すこと。
- 文法解析で役割が決まったら、その役割の観点を**選んで**光を通す（重みを足すより、光の器に合う）。手がかりが 2 つ以上なら割合の掛け算（実験52・55）。
- 動詞の側にも語板（食べる → が の観点 → 名詞の仲間）を持たせ、主語と述語の両側から光を通して掛け算する。片方の席に入っていなくても、もう片方から引ける。
- いまの穴: (1) 値の席が足りない（語板 v3 の が の観点に「食べる」がない、[名札の表](output_tags_v3.md)）、(2) が の観点は「名詞 が 動詞」がすぐ並ぶ形だけ（主題の「は」、離れた主語は取れない → GiNZA の係り受けで数え直す）。

## 5. 丸めで大事な語・文が消える問題（持ち主 2026-10-31）

持ち主: 「文法解析で文をまとめるたびに丸めが起きる。重要な単語・品詞のセットや、間違ってはいけない一文が長い文章で消える。新しい語板は丸められると次に出てこない。『敵を倒す呪文はアダブラカタブラだ』→ 語板 アダブラカタブラ の属性が『だ』『は』では引き出せない」。

- 係り受けで「だ・は」ではなく、つながりを取る: アダブラカタブラ → 呪文の一種（X は Y だ）、用途 = 敵を倒す（修飾）。上向きのつながりとして新しい語板に持たせ、「敵を倒す呪文は？」は 呪文 × 倒す の転置索引の掛け算で引く。少なくても中身の濃い属性で引ける。
- 丸めない記憶を別に持つ（意味の記憶 = 語板、出来事の記憶 = バッファ）: 新しい固有名詞の文・定義・数字・相手の指示は、文そのものを索引つきで残す。新しい語板はしばらく丸めずに強く学ぶ（類似バッファ）。自覚（実験62）で知らない語・意外な文に「丸めない」印。

## 6. 会話のバッファと記憶の層（持ち主の第 3 案、2026-10-31）

持ち主: 「語板は長期記憶。詳細な会話には会話のバッファが要る」。

| 案 | 中身 | 評価 |
|---|---|---|
| 3-1 短期・中期の記憶グレイン | 小さな語板群のように属性と名札のセットを持ち、その間だけ有効。薄まった名札は捨てて新しい名札と入れ替える。ずっと残る記憶は長期の語板の属性と名札を更新 | 全体の形として正しい（海馬と大脳の役割分担と同じ）。決めるのは「何を残すか」の基準（使われた回数・光の強さ・自覚の意外さ） |
| 3-2 文章ごとに消える観点 | 観点周波数を増やし、1 文章（会話）の間だけ書き換わる共通属性の観点。新しい語板にその属性を紐づける（アダブラカタブラ ← 敵 + 倒す + 呪文） | 3-3 を光の器でやる形。ザキラ（長期の語板で同じ属性）は、この文章の観点に光がないので掛け算で負ける |
| 3-3 文章に出た語へのバイアス・増幅 | 1 文章に出たすべての語に、属性からの語の選び方の増幅をかける。差分は文章に紐づける（アップル vs リンゴ） | 言語モデルの「キャッシュ」とほぼ同じで効果が確かめられている。語は数百なので手間は小さい。長期の語板は書き換えない → いちばん先にやる |

重ね方: 3-3（文章の中のキャッシュ）→ 3-2（観点の光で）→ 3-1（短期 → 中期 → 長期の移し替え、寝ている間に PC で）。
実験81 の案: Web 小説で「前に出た名詞がずっと後でまた出る所」を当てさせ、長期の語板だけ / 文章のキャッシュで増幅 を比べる。

## 7. これから書くこと

- 係り方の候補の並べ方と、語板による点の付け方（「頭が赤い魚を食べる猫」）。
- 一時語板（前の文の語に、その文での属性を付けた板）。
- 木から語の並びに直す決まり（述語は最後、修飾は前、活用）。
- 逆引き（転置索引）と上向きのつながり。
