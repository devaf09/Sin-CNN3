# 出口の名札（語板 v3、全部の語板で共通）

語板 v3（3 万語）の出口の番号と、観点ごとの値の名前。観点の光（観点 1 = どんな … 観点 9 = は、周波数 1〜9）を通すと、出口の番号（周波数 10 + 番号）に明るさが出る。
同じ番号の出口を、観点ごとに違う値が使う（観点の光どうしは混ざらないので、観点が違えば同じ出口でよい）。値の置き場所は観点ごとに 9 ずつずらしてある（実験58。よく出る値が同じ出口に重ならないように）。45〜53 番は観点ごとの「その他」（上位 45 値の外）。
