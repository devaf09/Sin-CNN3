# 一時まとめ（2026-10-31、実験55〜77）— 語板・属性樹・属性変位まで

持ち主「根本的な変更が必要そうだ。今の成果物は使えるかもしれないから、整理や一時まとめまで残しておいて」（2026-10-31）。
ここまでに作ったもの・分かったこと・使えそうなもの・限界を 1 枚にまとめた。数字の正本は [NOTES.md](../NOTES.md)、データの形は [data_structures.md](data_structures.md)。

## 1. 一言でいうと

- **1 語 = 1 枚の光の器（語板）で、語の使われ方（観点 × 値の割合）を、数えた表とほぼ同じ精度で覚えられる**。名詞 3 万語、表との差 0.024 ビット（語板 v3）。器は「板の枚数」を増やすのがいちばん割に合う。
- **ただし、語板が持っているのは「同じ文の中での使われ方」だけ**。前後の文から間の文の語を当てる（属性変位）と、光を使わない数え方の目安に大きく負ける（会話 0.21 対 0.49）。
- 語の属性の割合は「は 無い・が 有る・どんな 無い」のような、どの名詞にも付く属性が上に来て、上位 3 つで 2〜3 割しかない。文体（青空文庫・Web 小説）によらない。**観点の数え方そのものの癖**。

## 3. 分かったこと（使えそうな知見）

| 知見 | 数字 | 出どころ |
|---|---|---|
| 光の器は「違う入口から同じ出口に集められる光の和 ≤ 1」。出口を観点ごとにずらすと表に追いつく | 差 0.03〜0.05 | 実験56〜58 |
| 器を大きくするなら板の枚数 | 縦 64 × 板 16 で差 0.05、縦 128 × 板 16 で 0.025。500 回で十分 | 実験75 |
| 計算量は 縦 × 板 にほぼ比例。語板 1 枚・1 回 10〜38 µs | 3 万語を 500 回で 9 分（GPU 1 枚） | 実験75 |
| 融合は明るさで足す（位相を混ぜない） | 融合は完全、表す力とは引き換え | 実験64・66 |
| 合成の語板は親からの差分で持てる | 位相が 0.2 ラジアン動くだけ | 実験74 |
| 「持っていく属性が少ない向き」だけで合成の向きを決めると、意味の薄い組が選ばれる | 前 1.5%・後ろ 3.1% | 実験74 |
| 属性樹は根に近いほど共通の属性で、3 万語中 1.8 万語が根に残る | 節 1,471 | 実験71・count_totals |
| 当たりは「語の多さをそろえて」測らないと、よく出る語が当たって見える | 1 回目の「負け」の原因 | 実験76b |
| 属性の流れは手がかりになる（深い属性だけ使う）。木とメッシュは同じ | 会話 0.151・小説 0.071（でたらめ 0.052） | 実験76b〜f |
| 光をそのまま逆に入れるなら「その他」を除いて位相込みで | 会話 0.129 | 実験76h |
| **隣の文の観点を足すと良くなるが、仲間 100 組では粗い** | 会話 0.213・小説 0.104・Web 小説 0.091、目安 0.49・0.26・0.17 | 実験77 |

## 4. 限界（根本的な変更を考えるときの材料）

1. **観点が「同じ文の中の決まった型」だけ**（名詞 + 助詞 + 動詞、A の B など）。係り受けを見ていないので、離れた語のつながり・否定のかかる範囲・文と文のつながりが取れない。→ GiNZA（係り受け）を入れた。文法解析グレインの開発は計画に残してある。
2. **属性の割合が平たい**: どの名詞にも付く述語（無い・有る・成る・為る）が上に来る。その語らしさは「全体の割合で割る」と見えるが、器が覚えている形そのものは平たい。
3. **出口の数の上限**: 1 つの観点に値 45〜100 個。隣の文に出る語のように種類が多いものは、仲間に丸めるしかなく、細かさが落ちる。
4. **名詞だけ**（v2・v3）。動詞・形容詞の語板は v1 の 3000 語だけ。
5. 属性樹（木）は親が 1 つ。メッシュにしても属性変位の当たりは同じだった。

## 5. 次に使えそうな道

- 係り受け（GiNZA）で観点を取り直す（主語・目的語・修飾・否定の範囲、文をまたぐ指し示し）。
- 隣の文の観点を 2 段の仲間（粗い仲間 + 細かい仲間）にする、または値の多い大きな器。
- 属性の割合を「珍しさで割った形」で学ばせる（目標の作り方を変える）。
- 動詞・形容詞の語板を v3 の器で作り直す。
