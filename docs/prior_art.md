## 1.5 Sin-CNN3 の器は車輪の再発明か（2026-10-27、持ち主の疑問）

- **器の形**（位相の板 + 回折を何枚も、学習は計算機）は D²NN（2018）と同じ。
- **観点周波数で働きを切り替える**ことも、照らし方（波長・位相の鍵・角度）による多重化として 2023〜2026 年に研究されている。
- 見つからなかったもの（検索の範囲、網羅ではない）: 観点ごとの**逆引き**と**掛け算**による推し量り（実験21・24〜26）、関係を**つなげて**たどる（実験17）、知らない意味に**気づいて書き込む**（実験27）、拡散と「なし」の使い分け（実験23）。光で確率的な推し量り（ベイズ）をした例も見つからなかった。
- まとめ: 部品（器と多重化）は既にあるが、それを**記憶と推し量りに使う組み合わせ**は、見つけた範囲では新しい。

## 3. 調査から分かった、次に借りたい考え方

1. **取り出しの非線形で容量を上げる**（現代版 Hopfield）: 線形の重ね書きは N/(2 ln V) 止まり（実験08）だが、鋭くする部品（実験22 の 2 乗）を取り出しに入れると、容量が大きく増えるはず。
2. **きれいにする段**（HRR）: 推し量りの後に「一番近い記号に戻す」段（実験22 の 2 乗の部品をくり返す）を置くと、何段もたどるときに雑音がたまらない。
3. **光そのもので学習する**（in situ 逆伝播）: 逆向きに通す（実験21）と同じ形で、学習の傾きも光で測れる。
4. **注意（attention）**: 「問いの光」と「鍵の光」の重なりで、前の語を足し合わせる。語の順番と長い文脈が足りない部分を補う候補。
