# 大規模な学習の計画（案）— 語板を数万語へ

2026-10-28 作成（実験56 の後）。持ち主「そろそろ大規模な学習の予定を考えないとかなぁ」への案。決まったら、ここを書き換える。

## 1. いまの規模と、何がボトルネックか

| 項目 | いま（実験56） |
|---|---|
| 語板の数 | 名詞 1200 + 動詞 300 |
| 観点 | 名詞 5（どんな・を・が・で・に）、動詞 4（を・が・で・に） |
| 器 | 1 枚 = 縦 64 × 画素の板 8 列（位相 512 個）。出口の値は観点ごとに最大 54 個 |
| 学習の時間 | CPU で 1 seed 約 50 秒（全部まとめて計算） |
| 材料 | 会話 3 つ（非公開）、延べ 1600 万語。そのうち観点の形（名詞 + 助詞 + 動詞 など）に当たるのは学習用 49 万回 |

**いちばんのボトルネックは材料の量**。観点の形に 50 回以上出る名詞は 1295 語、20 回以上で 2936 語、10 回以上で 5242 語しかない。
数万語の語板を作るには、材料を 10〜50 倍に増やす必要がある。計算（GPU）は、まだ余裕がある。

## 2. 段階の案

各段階に「次へ進む条件」を置く。条件を満たさなければ、その段階で原因を調べる。

### 段階 1: 語板の学び方を整える（CPU、数時間）— **済み（実験57・58、2026-10-28）**: 平らにした目標 + 値の出口のずらしで、まれな名詞の差 0.01 ビット

- 目標の表を「観点ごとの割合へ寄せて平らに」してから語板に学ばせる（実験56 で、平らにした表 2.55 に語板 2.70 が負けた分を取り戻す）。
- 近い語板の選び方を、意味の近さ（逆引きの明るさの似方）で行う。
- 形容詞の語板（観点 = どんな名詞を修飾するか、何が〜か）を足す。
- **次へ進む条件**: まれな名詞で、語板が平らにした表との差 0.05 ビット以内。

### 段階 2: 材料を増やす — **進行中**（持ち主の許可「ライセンスに問題なければすべての資料の収集を許可」2026-10-28）。青空文庫の本文全体・Tatoeba は数え終わり、ウィキペディアを数えている

候補（どれもライセンスを確かめてから。取得は持ち主の許可のあと）:

| 材料 | 量の目安 | ライセンス | 向き・不向き |
|---|---|---|---|
| 青空文庫の本文全体（会話文だけでなく地の文も） | 手元にある 4,477 作品（圧縮で 134 MB） | 著作権切れ | すぐ使える。言葉が古い |
| 日本語版ウィキペディア | 圧縮で約 4 GB | CC BY-SA 4.0 | 物の属性（色・形・用途）が多い。会話ではない |
| 会話のコーパス（追加） | − | 個別に確認 | 会話らしさ。ライセンスが厳しいものが多い |

- まずは手元の青空文庫の本文全体で、材料を数倍にする（ダウンロード不要）。
- **次へ進む条件**: 観点の形に 50 回以上出る名詞が 5000 語以上。

### 段階 3: 数万語の語板（GPU）

- 語板 1 万〜3 万枚（名詞・動詞・形容詞）。計算は語板の数に比例するので、いまの 1500 枚 50 秒から見て、CPU で 1 seed 5〜20 分、GPU（RTX 3060 × 2、12 GB）ならその数分の 1 の見込み（実測で直す）。
  メモリは 3 万枚でも数 GB で、GPU 1 枚に入る見込み。
- 出口の値を増やす（観点ごとに数百の値）には、器の縦を 64 → 256 にする。計算は約 4〜5 倍。
- **気をつける器の上限**（実験41・56）: 違う入口から同じ出口へ大量の光を集められない。観点ごとに出口を分ける。値が増えると、1 つの答えに届く光は減る。
- **次へ進む条件**: 学習に使っていない会話で、語板が平らにした表との差 0.1 ビット以内。逆引きの上位が意味を持つ。

### 段階 4: 文の中で使う

- ○○ 当て（実験52・55）に、注意機構（実験49、番地に並べる）・位置の重み（実験52）・否定（実験53、1 − p）を入れて、実際の文で試す。
- 次の語の予測を、語板 + 2 段の器（実験38・54）で。比べ相手は n-gram。
- **次へ進む条件**: ○○ 当てで、平らにした表の掛け算に追いつく。次の語の予測で 3-gram に近づく。

## 4. 並行する研究の道筋（持ち主のアイディア 2026-10-29）

語板の大規模化（段階 3〜4）と並行して、小さな実験から始める。

| 道筋 | 中身 | 最初の実験の案 |
|---|---|---|
| ① 自覚グレイン（自覚関数） | 語板の出口の光の広がり（明るさの偏り = エントロピー、外へ逃げた光、2 番との差、複数の語板どうしの食い違い）から、確信度・不確実性を出す。短期的にはハルシネーション（もっともらしい間違い）予防 | 実験61 の語板で、○○ 当ての「出口の広がり」が、当たり・外れをどれだけ見分けられるか（確信度の較正）。学び 27 の「知らない意味は暗い」も材料 |
| ② 行板 → 章板 → 本板 | 1 行の語板を明るさで足して融合（学び 34）し、行板 → 章板 → 本板。本の属性の早見表。属性の光を逆に通して「どの行・章から来たか」を引き出す | 小さな文書で、行板の融合と、属性からの逆引き（どの行か当てる） |
| ③ 相関から因果へ | 差分（学び 44: 明るさで引く）・否定（学び 53: 1 − p）・不確実性（①）を組み合わせ、「緑と酸っぱいの相関は、未熟が原因」を見つける。介入（塗る = 色だけ変える）と観察（緑のトマトを見る）を分ける | リンゴ・トマト × 色 × 熟し具合の小さな表で、差分から「未熟 → 酸っぱい」を取り出し、「塗ったら酸っぱくなるか」に答えさせる |

③ は、統計学の「交絡」（未熟が、緑色と酸っぱさの両方の原因）と、「介入」（do 演算、Pearl）の考え方そのもの。光の器では、観点周波数を掃引して板を並べて比べ、
かすかな光（弱い属性）も捨てずに使う（持ち主の「デジタルの重みに変えない」）。

## 5. 設計の工夫の一覧（光の語板を大きくするときの決まり）

実験で分かった・持ち主が出した工夫を、ここに集める。

| 工夫 | 中身 | 出どころ |
|---|---|---|
| 初期の板は 2 値（0 か π）のばらばら | 学習が速く、重い課題でも遅れない | 実験45・46 |
| 目標の表を平らにしてから学ぶ | まれな語の当てにならない数を全体の割合で補う | 実験57 |
| 同じ出口に光を集めすぎない | 光の量を保つ器では、違う入口から同じ出口へ届く光の和は 1 まで。「その他」・多い値の出口を観点ごとにずらす | 実験56・58 |
| 材料の混ぜ方で性格を決める | 会話に強くするなら会話を 30〜100 倍に数える | 実験60・61 |
| 逆引きには語の多さを掛ける | P(語 | 値) ∝ P(値 | 語) P(語)。まれな言い回しに引っ張られない | 実験59・61 |
| 「〜ではない」は残りの光（1 − p） | 範囲の広い否定でも崩れない | 実験53 |
| 干渉で表し、明るさで混ぜる | 融合は出口の明るさで。板の位相は混ぜない | 実験34・64 |
| 非線形は明るさの規模をそろえてから | カー効果は明るさ ÷ 平均で。焦点面でかける | 実験54 |
| 何段もたどるときは明るさの p 乗 + 利得 | 濁りがたまらない | 実験47・50 |
| **属性の重要さで、観点周波数に割り当てる属性を選ぶ** | 属性は付けるほど増えるが、新しく増える種類は減っていく。知性樹の段（根に近いほど重要・共通）と共通の度合いで重要さを決め、「8 段目まで」（エッジなら 4 段目まで）の属性を観点周波数に割り当てる。最初にある程度学習してから、知性樹の幅を観点周波数の幅に合わせる（定期的に見直す） | 持ち主の案 2026-10-29、実験65 |
| **語板 = 本文、行板 → 章板 → 単位板 = グレインを大きくした索引** | 語ごとの語板は正確（表との差 0.02）。行板・章板・単位板は、1D のグレインを縦に広げて語を入口の周波数で重ね（または 2D）、属性の光を逆に 1 回通すと全部の語を走査できる（上位 5 語の 85% が表と一致）。索引で候補を絞り、本文（語板）で確かめる。章を合わせる単位板は、章板を明るさで並べて足す | 実験66〜68、持ち主 2026-10-29 |
