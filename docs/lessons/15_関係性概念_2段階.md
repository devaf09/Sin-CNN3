# 学び 15: 関係性概念 — 1 つの入力に複数の点（第 1 段階）と、ずらして別の点へ（第 2 段階）

2026-10-27。実験15（experiments/exp15_relations.py）。持ち主の依頼:

> 関係性概念とでもいうべきなんだろうか。ホログラムでいうとみる方向が変わると出てくる値が変わるに似ている。まず一つの入力に対して 1 個かそれ以上の対応する点を作る（A → B, C, D / B → C / D → A, E, F / X → Y, Z）。入力と出力は同じ仕組みで可逆的に変換できることが望ましい。次に第二段階、参照光に代わる何かを探す。縦軸の光の周波数を少しずらすことを考えている。これにより A → G, H のように、異なる点の調整をして焦点を合わせてほしい。うまくいかなくてもその原因を教えてほしい（全体が動いてしまうからとか）。（2026-10-27 持ち主の依頼、要約）

## 何をしたか

- **器**: 学び 12・14 と同じ（縦 100 画素、100 列、列の間 64 画素、周波数 1〜16、縦横とも sin と cos）。曲がる処理なし。
- **記号**: 11 個（A B C D E F G H X Y Z）を縦に約 8 画素おきに並べた。入力は記号の位置の光の点（幅 1.5 画素）、出力は右端の同じ位置の窓（4 画素）。**入力と出力が同じ並び**なので、出力をそのまま次の入力にできる。
- **第 1 段階**: A → B, C, D / B → C / D → A, E, F / X → Y, Z。
- **第 2 段階**: 入力に e^(i·2π·δ·y/100) を掛ける（縦の周波数を δ だけずらす = 光を少し傾けて入れる = ホログラムを見る方向を変える）。ずらしたときは A → G, H（持ち主の例）、B → F、D → B, C、X → E, F, G（A 以外は私が決めた例）。δ = 0.25〜8。
- **学習**: 答えの点に光を等しく集める（窓の外も「はずれ」として数える）。Adam（学習率 0.01）1500 回、3 seed。1 回 30 秒ほど。
- 学習前と後の光の 2 次元マップ・格子・出力は results/exp15_maps/ に残した。

## 第 2 段階の結果

![第 2 段階: ずらしの量と成績、入力の重なり、δ = 8 での切り替え](../images/exp15_stage2.png)

| ずらし δ | 組がぴったり | 答えの窓に入った割合 | 出口に届いた光（seed 0） | 入力どうしの重なり（式） |
|---|---|---|---|---|
| 0.25 | 50% | 49% | 63% | 0.9999 |
| 0.5 | 54% | 47% | 50% | 0.9997 |
| 1 | 50% | 45% | 53% | 0.9989 |
| 2 | 63% | 52% | 48% | 0.996 |
| 4 | 75% | 60% | 37% | 0.982 |
| 8 | **100%** | **89%** | **6%** | 0.93 |

- **少しのずらし（δ ≤ 2）では切り替わらない**。50% = 「ずらしなしの答え」と「ずらしありの答え」に光を半分ずつ配る、どっちつかずの答え。
- **大きくずらす（δ = 8）と全部当たる**。同じ A が、ずらしなしでは B, C, D、ずらしありでは G, H に光る（右の図）。**ただし、出口に届く光は 6%**。残り 94% は、器が出口の外へ捨てている。

## なぜか（式で説明）

1. **細い光の点は、もともといろいろな向き（周波数）の光を含んでいる**。幅 1.5 画素の点の周波数の広がりは約 20 周ぶん。そこに δ = 1 のずらしを足しても、光はほとんど変わらない。式で、ずらす前と後の光の重なりは δ = 1 で 0.9989（1 = まったく同じ光）。
2. **曲がる処理のない光の器は、光の量を保つ（学び 02・09）。光の量を保つ器は、2 つの入力の重なりも保つ**。入力がほとんど同じなら、出力もほとんど同じにしかならない。だから「どっちつかず」（50%）になる。
3. δ = 8 でも重なりは 0.93。器は、2 つの入力に共通する部分（93%）を出口の外へ捨て、違う部分だけを答えの点に集めて見分けた。だから当たるが光が 6% しか届かない。
4. 持ち主の見立て「全体が動いてしまうから」も、半分当たっている。この器（列の間 64 画素、100 列）では δ = 1 の傾きで光は全体で約 64 画素横へ動く。ただ、細い点の光はもともと四方に広がっているので、動いても「同じ広がり方の光」のままで、見分けの手がかりにならない。

## 分かったこと

- **第 1 段階（1 つの入力 → 複数の点）は、曲がる処理なしの光の格子で簡単にできる**。入力と出力を同じ並びにできるので、出力を次の入力にする（つなげる）こともできる。
- **第 2 段階（ずらしで別の点へ）は、「入力の光がずらしでどれだけ変わるか」で決まる**。細い光の点では、少しのずらしはほとんど何も変えないので、器がどんなにがんばっても見分けられない。見分けるには、入力の重なりを 0 に近づける必要がある。
- これは、ホログラムで「厚いホログラムほど、少しの角度の違いで別の像を出せる」のと同じ話で、ここでは「入力の光が広い（幅が大きい）ほど、少しの傾きで別の光になる」に当たる。

## 次の一手（第 2 段階をうまくいかせる案）

1. **入力を「幅の広い光」にする**: 記号を、光の点ではなく、縦 100 画素全体に広がる模様で表す。幅が広いほど、少しのずらしで重なりが 0 に近づく。
2. **持ち主の案「混ざらない周波数の光（素数的な）」で記号を表す**: 記号 = 縦 100 画素全体に広がる、整数の周波数の波。そこに整数の δ（たとえば 1）のずらしを掛けると、周波数が 1 つずれて、ずらす前と**ぴったり重ならない（重なり 0）光**になる（学び 06 の「整数の周波数は混ざらない」）。こうすれば、光を捨てずに切り替えられるはず。ただし、ずれた先が別の記号の周波数と重ならないように、記号の周波数の間をあける（例: 3 の倍数に置いて、ずらしは 1）。出力も同じ周波数の並びで読めば、入力と出力が同じ仕組みになる。
3. 周波数の位相や角速度の調整（持ち主の見立て）は、2 の形にすると「どの周波数を、どれだけずらすか」として、そのまま使える。
