# 学び 66: 2D の語板と、角度で何語も重ねる器（章板の模型）（実験66）

2026-10-29。実験66（experiments/exp66_2d_goban_fusion.py）。持ち主「単語を 2D にして、3D（2D の板数枚）で作っても融合の結果は一緒？ 語板 2D → 章板 3D → 単位板（3D の融合）。
計算量がいたずらに増えるだけならまた考えるけど、語板・章板・一単位板となるとき絶対に便利だと思う」。

## この記事で言いたいこと

1. **2D でも融合の性質は 1D と同じ**: 板の位相を混ぜると崩れ、出口の明るさで足すと完全、派生させると少し保てる。
2. **1 つの 2D の器に、入口の角度を変えて 32 語を重ねられた（章板の模型）**。板を厚く（4 枚 → 16 枚）すると、語ごとに別の器を持つのとの差は小さくなった（3.08 対 2.86 ビット）。
   **板の数（位相の数）は 32 分の 1**。
3. 重ねた器から、2 語の入口の光を「干渉しない形」で同時に入れると、答えはちょうど 2 語の平均になる（融合が完全）。同じ光源から入れて干渉させると、答えがゆがむ。

## 方法

- 板 = 縦 32 × 横 32 の位相（2D）を 4 枚または 16 枚。板の間は 2D の角スペクトル法（光の回折の式）。出口 = 2D のレンズで、決まった 52 個の点の明るさ。
- 材料: 会話の名詞（非公開）、観点 5、実験58 の決まり（平らにした目標・出口のずらし）。
- **A. 語ごとに 1 つの 2D の器**: 2 語ずつ組にして、3 つの融合（位相の平均・明るさの平均・派生 + 位相の平均）を比べる。
- **B. 章板の模型**: 1 つの器を全部の語で共有し、**語 w・観点 v の入口 = 横に w、縦に v だけ傾けた光**にする（体積ホログラムで、角度を変えて重ね書きするのと同じ考え）。
  重ねる語の数 W = 2・8・32。比べ = 語ごとに別の器。

## 結果

### A. 2D の語板の融合（20 組・16 組）

| | 板 4 枚 | 板 16 枚 |
|---|---|---|
| 当たり（語ごとの器、ビット） | 3.13 | 2.86（表 2.81） |
| 融合の差: 位相の平均 | 0.37 | 0.49 |
| 融合の差: 明るさの平均（並べて足す） | **0.009** | **0.003** |
| 融合の差: 派生 + 位相の平均 | 0.10 | 0.07 |

→ 1D（実験34・37: 0.72〜0.86 / 0.01 / 0.13〜0.27）と同じ並び。**次元を増やしても、融合の性質は変わらない**。

### B. 1 つの器に何語も重ねる（章板の模型）

| 重ねる語の数 | 板 4 枚: 共通の器 / 語ごとの器 | 板 16 枚: 共通の器 / 語ごとの器 | 値に届く光（16 枚） | 融合: 干渉しない / 干渉する |
|---|---|---|---|---|
| 2 | 3.61 / 3.35 | − | − | 0.007 / 0.22 |
| 8 | 4.17 / 3.32 | **3.08 / 3.01** | 18% | 0.008 / 0.24 |
| 32 | 4.39 / 3.18 | **3.08 / 2.86** | 6% | 0.009 / 0.24 |

（当たりは確かめ用の交差エントロピー、ビット、小さいほど良い）

## なぜそうなったか

- **融合の性質が次元によらない**のは、理由が「光は e^{i 位相} で効き、何枚も重なって通るので、位相に対して足し算にならない」だから。これは 1D でも 2D でも同じ。
- **1 つの器に何語も重ねられる**のは、語ごとの入口の光の角度が違い、互いに直交しているから（観点周波数・f2 のモード、学び 16・41 と同じ）。
  器は語ごとに別の通り道で光を運べる。**板を厚くすると、通り道を分ける力が上がる**（体積ホログラムで、厚いほど角度の選び分けが鋭くなるのと同じ）。
- **値に届く光は、語を増やすほど減る**（32 語で 6%）。光の量を保つ器では、重ねた語どうしで光を分け合うため（実験41・56 の上限と同じ）。
  割合で読めば当たりは保てるが、本物の光では、暗い光を読むための明るい光源や感度が要る。
- **干渉しない形で 2 語を同時に読むと融合が完全**なのは、明るさの足し算になるから（並べて足すのと同じことを、1 つの器の中でやっている）。同じ光源から 2 つの角度で入れると干渉して、答えがゆがむ（0.22〜0.24）。

## 考察 — 語板・章板・単位板への意味（持ち主の「絶対に便利」への答え）

- **章板 = 1 つの厚い器に、その章の語を角度で重ねたもの**として作れる。語ごとの器より位相の数が 32 分の 1（今回）で、当たりの低下は小さい。
  計算量（学習）も、語ごとの器 32 個より、厚い器 1 つの方が少ない（今回 114 秒 対 語ごとの器 32 個ぶん）。
- **章板の融合 = 語の角度の光を、干渉しない光源で同時に入れる**。板を混ぜないので壊れない。重み付き（比率）も、光源の明るさで決められる。
- **単位板（本）= 章板をさらに重ねる**。ただし、重ねるほど 1 語あたりの光が減る。章ごとの明るさの規格化（増幅）が要る。
- 計算量は「器を厚くするほど増える」。語の数に合わせて厚さを決める（32 語に 16 枚くらい）。

## 正直な限界

- 2D の器の当たりは、1D の語板（実験58、表との差 0.02）より表から離れている（板 16 枚で 0.05、4 枚では 0.3）。2D の器の作り方（板の大きさ・間隔・出口の点の置き方）はまだ調整していない。
- 重ねた語は 32 語まで。数百語・数千語を 1 つの器に重ねられるかは、まだ分からない（光が減る上限がある）。
- 体積ホログラムの本物の性質（厚い媒体の中の連続的な屈折率の変化）ではなく、薄い板を何枚も重ねた模型。
