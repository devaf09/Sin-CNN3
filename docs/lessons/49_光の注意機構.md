# 学び 49: 光の注意機構 — 鍵と値をどこに置くか（実験49）

## 何をしたか

持ち主の案で、トランスフォーマーの注意機構（attention）を光の言葉に置き換えた。

- 問いの光 = いま着目している語の模様
- 鍵の光 = 過去の位置ごとの語の模様
- 内積 = 2 つの光の重なり（相関）の明るさ
- 重み付け = softmax・べき・スパイク
- 値の加重平均 = 重みで値の光を通し、レンズで集めて足す

持ち主の方針で、トランスフォーマーの形は暫定とした。いずれもっと良い注意機構に入れ替えるので、部品 `src/attention.py` に分け、置き方と重み付けを名前で選べるようにした。

比べたのは、過去の鍵を置く 3 つの方法。

1. **番地（address）**: 鍵ごとに別の画素に並べ、1 つずつ相関を取る
2. **周波数の帯（band）**: 1 つの場を T 個の帯に分け、位置 t の鍵を帯 t に置く
3. **ホログラム（holo）**: 1 枚の板にすべての鍵を重ね書きし、相関面の点 t の明るさで読む

## 式の予想

- 重なりの明るさは、正しい位置で 1、でたらめな外れで平均 1/N。
- 2 と 3 は、点 N 個の場 1 つを文脈全体で分け合う。T が N に近づくと、混線（分散 T/N）や鍵の短さ（長さ N/T）で崩れるはず（実験47）。
- softmax の重みは exp(β·明るさ)。外れの明るさが 0 でも exp(0) = 1 の重みがつく。正しい位置の重みは e^β/(e^β + T − 1) に薄まるはず。

## 結果

- 番地に並べる置き方だけが、長い文脈で崩れなかった。N = 64 でも、T = 4096 で 100%。
- 帯とホログラムは、T が N の 1/4〜1 くらいで崩れた（N = 256 のホログラムで、T = 64 のとき 52%）。
- softmax（β = 8）での正しい位置の重みは、T = 256 / 1024 / 4096 で 0.92 / 0.74 / 0.41。式の 0.92 / 0.74 / 0.42 と一致した。
- べき・スパイクでは、直交した外れの重みは 0 で、正しい位置の重みは 1.00 のままだった。

## 分かったこと

- **長い文脈を持つには、過去の鍵・値を別々の番地に置く必要がある**（トランスフォーマーの KV キャッシュと同じ）。
  記憶は文脈の長さに比例して増える。1 つの場に重ねる方法は、場の点の数で頭打ちになる。
- **「無関係な語は直交性で無視できる」は、重み付けがスパイク・べきなら成り立つ。softmax では成り立たない**。
  softmax は、何も重ならない位置にも重み 1 を配る。光で「明るさを p 乗する」「いちばん明るい所だけ通す」方が、長い文脈には向いている。
  ただし、スパイクは答えを 1 つに決めてしまい、2 つ以上の候補を混ぜられない。softmax の良さ（なめらかに混ぜる、学習で勾配が流れる）とのかね合いになる。
- 整数の周波数 1 本で表した鍵は、相関面の点の明るさでは読めなかった。自己相関が山にならず、情報が位相にしか出ないため。
  周波数で表した記号を注意機構で使うには、レンズで周波数の位置に集める読み方が要る（これは「番地」の読み方と同じになる）。

## 残った疑問（もっと良い注意機構へ）

- 番地の数は文脈の長さだけ要る。古い番地を、融合（実験34）で 1 枚にまとめていけないか。重要な語だけ番地に残し、ほかは重ねた板に入れる 2 層の記憶など。
- softmax とスパイクの間（べき p）を、学習中に変える。
- 語の順番を、鍵の位相のずらし（位置の周波数）で入れる。実験38 の 2 段の器と組み合わせて、次の文字の予測で試す。
