# 学び 27: 関係性の関係 — 知らない意味に気づき、何の仲間かを当て、新しい意味を書き込む

2026-10-27。実験27（experiments/exp27_unknown_sense.py）。持ち主の案:

> 逆説的にりんごさんを知らなくても、既存の果物リンゴに合わないとわかれば、それが別の属性で作られたリンゴという何か、とわかるし、関係性の関係という考え方を追加すると、それがすぐに人間のリンゴさんって分かるんじゃないかな。例: リンゴは楽しそうに手を振った。→ 手を振る: 人間、楽しそう: 人間の確率高い、「は」: 周囲の関連性を上げる → りんごは人間の属性を持つ。（2026-10-27 持ち主の案）

## 何をしたか

1 つの光の器（学び 21・26 と同じ作り、記号 22 個）に、**3 段の関係**を覚えさせた。

| 段（観点のずらし） | 覚えた関係 |
|---|---|
| 意味（0） | 文字列 → 物。「リンゴ」→ 果物のリンゴ（**人の意味は知らない**）、「ミカン」→ 果物のミカン、「太郎」→ 人の太郎、「ポチ」→ 犬のポチ |
| 仲間（1） | 物 → 仲間。果物のリンゴ・ミカン → 果物、太郎 → 人間、ポチ → 動物 |
| 行い・様子・味（2〜4） | **仲間 → 値**（属性は物ではなく仲間に持たせる = 関係性の関係）。人間の行い = 手を振った 30%・話した 40%・走った 30%、様子 = 楽しそう 60%・静か 40%。果物の行い = 食べた 60%・切った 40%、様子 = 静か 100% など（私が決めた表） |

そのうえで 3 つのことをした。

1. **驚き**: 文を「文字列 → 物 → 仲間 → 手がかり」とたどった明るさ（どれだけ合うか）を測る。
2. **仲間当て**: 手がかりだけを逆向きに通して掛け算し、どの仲間かを当てる（文字列を見ない）。
3. **書き込み**: 空いている記号「未知 1」に、「リンゴ」→ 果物のリンゴ 50%・未知 1 50%、未知 1 → 2 で当てた仲間、を足して、少しだけ学習し直す（200 回）。

1500 回、3 seed、1 seed 約 50 秒。

## 結果

![知らない意味に気づき、書き込む](../images/exp27_unknown_sense.png)

**1. 驚き**（たどった明るさ、3 seed）:

| 文 | 書き込みの前 | 書き込みの後 |
|---|---|---|
| リンゴを食べた | 2.6〜3.1 × 10⁻² | 1.2〜1.4 × 10⁻² |
| リンゴは楽しそうに手を振った（持ち主の例） | **1.4〜7.1 × 10⁻⁵** | 1.1〜1.5 × 10⁻³ |
| 太郎は楽しそうに手を振った（比べ） | 4.7〜5.5 × 10⁻³ | 2.2〜2.7 × 10⁻³ |
| ポチが吠えた | 3.2〜4.0 × 10⁻² | |

**2. 仲間当て**（手がかりだけ）: 「楽しそうに手を振った」→ **人間 95〜100%**（3 seed とも）。「食べた」→ 果物 96〜99%、「吠えた」→ 動物 94〜97%。

**3. 書き込みの後**の「リンゴ」の意味:

| 文 | 意味の点数（3 seed の平均） |
|---|---|
| リンゴを食べた | 果物のリンゴ 98% |
| リンゴは楽しそうに手を振った | **未知 1（人間の仲間）99%** |
| リンゴが話した（書き込みでは見せていない手がかり） | **未知 1 97%** |

前の関係の表との差: 0.10 → 0.11（ほとんど崩れない）。

## 分かったこと

- **知っている意味に合わない文は、たどった明るさがとても暗い**。「リンゴは楽しそうに手を振った」は、同じ手がかりの「太郎は〜」より 75〜340 倍暗い。この暗さが「知らない意味がある」という合図（驚き）になる。持ち主の「既存の果物リンゴに合わないとわかれば、別の何かとわかる」がそのまま起きている。
- **属性を仲間（上の段）に持たせておくと、知らない物でも手がかりから仲間を当てられる**。「手を振った・楽しそう」→ 人間 95〜100%。持ち主の「関係性の関係」。
- **当てた仲間で新しい意味を書き込むと、すぐに使える**。書き込みに使わなかった手がかり「話した」でも、「リンゴが話した」→ 人間のリンゴ 97%。人間の仲間の属性を、上の段から受け継いでいるため。果物のリンゴは「食べた」で 98% のまま残る（2 つの意味が並ぶ = 学び 26 の形が、自分で作れた）。
- 書き込みは、今回は「少しだけ学習し直す」でした（前の関係の差は 0.10 → 0.11）。学習なしで重ね書きする方法（学び 08）は、まだ試していない。
- 「は」で周りの手がかりを強く効かせる（持ち主の案）は、まだ入れていない。手がかりが互いに食い違う文（「リンゴは手を振った、甘かった」など）で試すのがよさそう。
