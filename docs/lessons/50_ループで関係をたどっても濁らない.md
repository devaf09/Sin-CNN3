# 学び 50: 非線形のループで、関係を何段たどっても濁らない（実験50）

2026-10-28。実験50（experiments/exp50_chain_cleanup.py）。

## 目的

実験17 では、出口の光をそのまま次の入力にして、関係を A → B → … → F と 5 段たどれた。ただし 1 段ごとに光が約 7% 減った。
本物の装置では、光が減るだけでなく、板のずれや雑音で光の模様も少しずつ濁る。何十段もたどると、答えが分からなくなるはず。

学び 47（実験47）で、「明るさを p 乗して組み直す」ループが、濁った鍵をきれいに戻すと分かった。
これを関係のたどりに入れれば、何段たどっても濁らないかを確かめる。持ち主の案 2「記憶ループ（板 → 回折 → 非線形の利得媒質 → 板へ戻す）」の当てはめ。

## 理由（なぜ濁りが戻ると考えたか）

1 段のたどりを、注意機構（学び 49）の形で書く。

1. 問いの光 q と、覚えた鍵 k_i の重なりの明るさ I_i を取る（相関）
2. 明るさから重み w_i を決める
3. 次の問い = Σ w_i k_{i+1}（次の鍵を重みで足す）、明るさを 1 に戻す（利得）

濁った問いでは、正しい鍵の明るさは 1 より小さく、ほかの鍵にも少し明るさが出る。
- 重みが明るさそのまま（p = 1）なら、ほかの鍵の分も次の問いに混ざり、濁りが積み重なる。
- 明るさを p 乗すると、正しい鍵（いちばん明るい）だけが大きく残り、ほかはほぼ 0 になる。次の問いは、正しい次の鍵そのもの（きれい）に戻る。
これは、デジタル回路で「0 か 1 に戻す」ことで雑音がたまらないのと同じ考え方。

## 方法

長さ N = 64 の鍵を 256 個、ひと回りの鎖として覚える（記憶は番地に並べる形、src/attention.py）。
1 段ごとに、装置の不完全さとして位相の雑音（σ = 0.6 で重なり 約 0.70、σ = 1.0 で約 0.37）と光の減り（× 0.93）を入れる。30 段たどる。

比べた重み付け:
- 線形: 1 枚の板に「鍵 → 次の鍵」を重ねた行列をそのまま通す（M = 256 > N = 64 なので重ねすぎ）
- 明るさの 1 乗・2 乗・4 乗、スパイク（いちばん明るい鍵だけ）

## 結果

![実験50](../images/exp50_chain_cleanup.png)

| 重み付け | 雑音 σ = 0.6: 1 / 10 / 30 段後の重なり | 雑音 σ = 1.0: 1 / 10 / 30 段後 |
|---|---|---|
| 線形（1 枚に重ねる） | 0.16 / 0.02 / 0.02 | 0.10 / 0.02 / 0.02 |
| 明るさの 1 乗 | 0.80 / 0.31〜0.39 / 0.03〜0.07 | 0.54 / 0.02 / 0.02 |
| **明るさの 2 乗** | **1.00 / 1.00 / 1.00** | **0.98 / 0.97 / 0.97** |
| 明るさの 4 乗・スパイク | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |

（3 seed、どれもほぼ同じ。30 段後の正解率も、2 乗以上は 100%）

- **明るさを 2 乗以上して組み直すと、雑音と光の減りが毎段入っても、30 段たどって濁らなかった**。
- 明るさの 1 乗では、10 段で重なり 0.3 に濁り、30 段でほぼ消えた。
- 1 枚に重ねた線形の板は、そもそも 256 組を覚えきれず（M > N）、1 段目から崩れた。

## なぜそうなったか

- 1 乗では、毎段、ほかの鍵からの小さな明るさ（外れ）が次の問いに混ざる。混ざった分はそのまま次の段の外れを増やすので、濁りが積み重なる。
- 2 乗以上では、外れの明るさ（約 1/N）が 1/N² 以下に縮み、ほぼ消える。正しい次の鍵だけが残るので、毎段「きれいな鍵」から出発し直せる。
  雑音で正しい鍵の明るさが 0.37 まで下がっても、いちばん明るいことさえ保たれていれば元に戻る。
- 光の減り（7%/段）は、明るさを 1 に戻す利得（光の増幅、可飽和吸収や注入同期）で補える。

## 分かったこと

- **非線形のループ（明るさの p 乗 + 利得）は、関係を何段たどっても光を濁らせない部品になる**。持ち主の案 2 の記憶ループは、この役で効く。
- ただし、効くのは鍵を別々に呼べる記憶（番地に並べる）のとき。1 枚に重ねた板では、重ねた時点の混線が消せない（学び 47）。
