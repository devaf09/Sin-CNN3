# 学び 65: 知性樹 — 共通の属性で語板を絞り込み、親子の差を残した木（実験65、最初の形）

2026-10-29。実験65（experiments/exp65_knowledge_tree.py）。木そのもの: [docs/knowledge_tree_65.md](../knowledge_tree_65.md)。

## 目的（持ち主の案）

> 同じ属性を持つ語板から、属性の不確実性が低い板の上位数割を抽出する。その語板から関連性の高い属性を探す（抽出した板を融合して 1 回で）。
> これを繰り返すと、最終的に残った板の属性は拡散する。その一つ前に戻って何が違うのかを調べる。ルートまで戻ったら 2 番目の属性で同じことを。
> 属性グレイン → 語板の対応ツリー。ツリーの親子は結構似ているはず。知性樹に。

## 方法

会話の材料の名詞 1200 語の語板（実験58 の決まり）。各節（語板の集まり）で:

1. **融合した板** = 集まりの語板の出口の明るさの平均（学び 34 の確実な融合）。
2. 各属性（「を 見る」など）を「持つ」語板の割合 = 共通の度合い。大きい順に、まだ使っていない属性で枝を作る（1 つの節から最大 3 本）。
3. 枝の集まり = その属性を持つ語板のうち、その属性の割合（確信度）が高い上位 5 割（最低 3 枚）。
4. **属性差グレイン** = 子の融合した板 − 親の融合した板（どの属性が強まり、どれが弱まったか）。
5. 共通の度合いが 5% 未満・3 枚未満・深さ 4 で止める（葉）。

## 結果（抜粋。全体は knowledge_tree_65.md、節 30 個）

- 根（1200 語）→ **が 多い**（63 語）→ **に 嵌まる**（ゲーム・漫画・筋トレ・スイッチ・アニメ・動画・ドラマ…）
  → **どんな 好き**（アニメ・漫画・作品）/ **どんな 面白い**（動画・ドラマ・作品）/ **に 出る**（アニメ・ドラマ・動画）
  - 属性差: 「に 嵌まる」に進むと「を 見る」+0.16・「どんな 好き」+0.12 が強まり、「に 成る」「に 行く」が弱まる。
- 根 → **どんな 早い**（75 語）→ **が 来る**（迎え・冬・御迎え・警察・秋・連絡）→ **に 来る**（迎え・御迎え・連絡）
- 根 → どんな 早い → **に 出る**（電話・体調・表・試合・行動）→ **に よる**（電話・体調・試合）
- 根 → **を 為る**（真似・邪魔・買い物・怪我・掃除…）→ **が 出来る**（買い物・真似・我慢）

## 分かったこと・考察

- **持ち主の見立てどおり、親子はよく似ている**。子は親の属性をほぼ受け継ぎ、属性差グレインは少しの属性だけが強まる・弱まる形（例: +0.1〜0.3 が数個）。
- 葉に並ぶ語は、意味の仲間になっていることが多い（アニメ・漫画・ドラマ・映画、迎え・御迎え・連絡）。
- **同じ枝に「使い方が同じだが意味は違う」語が入る**: 「に 出る」→ 電話（電話に出る）・体調（体調に出る）・試合（試合に出る）。
  木は「意味」ではなく「使われ方」で分かれる。これは語板が使われ方を覚えているから当然で、言い回し（多義）を見つける道具にもなる。
- 葉は、ほとんどが「3 枚まで減った」ことで止まり、「属性が拡散した」ことで止まった葉は少ない（共通の度合いの残りが 33〜100%）。材料（語の数）を増やすと、より深い木になるはず。
- 上の方の枝は「を 為る」「が 多い」のような、どの名詞にも多い属性になりやすい（共通の度合いで選ぶため）。「その属性らしさ」（全体の割合との比）で選ぶ形も試したい。

## どう使うか（持ち主の「さてどう使おうか」への案）

1. **知らない語の学び始め**（学び 51 の続き）: 新しい語の手がかりから、木を根からたどって一番合う節を探し、その節の融合した板から学び始める。近い 1 語を写すより、仲間の平均から始める方が安定するはず。
2. **説明**: 答えの理由を「根 → が 多い → に 嵌まる → どんな 好き」の道筋で示せる（なぜアニメと漫画を仲間と考えたか）。
3. **因果（学び 62 の ③）の候補**: 兄弟の節の差（属性差グレイン）は、「この属性が違うと、何が一緒に変わるか」の候補。
   実験63 のように、ほかが同じで 1 つだけ違う組を木の中から探せば、介入の効き目を見積もれる。今の属性差は相関で、介入にするにはその確かめが要る。
4. **圧縮**（大規模になってから）: 語板を「節の融合した板 + 小さな差」で持てば、似た語の重なりを省ける。
