# 学び 32: 道具の要素 × 単語の格子 → 結果（ミキサーとリンゴ）

2026-10-27。実験32（experiments/exp32_tools.py）。持ち主の案:

> 入側に「ミキサー」という要素・属性（文字列とか）があってそれがリンゴの格子に入るとジュースの属性になる。入側に「プレス機」という要素・属性があって、それがリンゴの格子に入るとジュースになる。入側に包丁・ピーラーに関連する要素をもつ何かがあれば → リンゴの格子からは皮をむく、調理、食べる、といった要素が出る。（2026-10-27 持ち主の案）

## 何をしたか

学び 31 の「単語ごとに格子 1 枚」の入口に、「何か」の代わりに**道具の要素の光**を入れた。単語の格子が「道具を受け取って結果を返す関数」になる形。
- 要素 5 つ: 刃・回転・圧力・熱・薄く。道具 = 要素の光の重ね合わせ（ミキサー = 刃 + 回転、プレス機 = 圧力、包丁 = 刃、ピーラー = 刃 + 薄く、鍋 = 熱）。
- 結果 7 つ: ジュース・細かい・皮をむく・切る・煮る・焼く・食べる。
- 単語 3 つ（リンゴ・ニンジン・肉）の格子（1 KB ずつ）を、私が決めた表で学習（例: リンゴ × ミキサー → ジュース 70%・細かい 30%、リンゴ × プレス機 → ジュース 100%）。1500 回、3 seed。
- **見せていない道具**: フードプロセッサ = 刃 + 回転（ミキサーと同じ要素で名前だけ違う）、**圧力鍋 = 圧力 + 熱（見せていない組み合わせ）**、ホットプレート = 熱（鍋と同じ要素）。
- **逆引き**: 「ジュース」の光をリンゴの格子に逆向きに通し、入口で要素ごとの明るさを読む（何を使えばジュースになるか）。

## 結果（3 seed、数字は % で、3 seed の範囲）

| 単語 | 見せていない道具 | 出た結果（上位） |
|---|---|---|
| リンゴ | フードプロセッサ（刃 + 回転） | ジュース 35〜41・細かい 21〜25 |
| リンゴ | **圧力鍋（圧力 + 熱）** | **ジュース 42〜48・煮る 35〜36**・食べる 12〜20 |
| リンゴ | ホットプレート（熱） | 煮る 63〜71・食べる 25〜35 |
| ニンジン | 圧力鍋 | 煮る 52〜56・ジュース 38〜42 |
| 肉 | フードプロセッサ | 細かい 67〜71・切る 21〜30 |
| 肉 | 圧力鍋 | 煮る 40〜53・細かい 28〜34・焼く 0〜24 |

**ジュースの逆引き（リンゴ）**: 圧力 64〜65%・回転 18〜25%・刃 11〜14%・熱と薄く 0〜2%（3 seed とも同じ順）。ニンジンも 圧力 66〜69%・回転 19〜24%。

学習した組の表との差は 0.17〜0.25（学び 31 の 0.06 より粗い。入口が 1 本の光ではなく要素の重ね合わせのため）。

## 分かったこと

- **見せていない組み合わせの道具（圧力鍋 = 圧力 + 熱）を入れると、リンゴの格子は「プレス機の答え（ジュース）」と「鍋の答え（煮る）」を合わせたものを返した**。光の器は重ね合わせが成り立つので、要素の光を足して入れると、答えも要素ごとの答えの重ね合わせになる。知らない道具でも、要素が分かれば「たぶんこうなる」と推し量れる。
- **逆引きで「ジュースにするには？」と聞くと、圧力（プレス機）と回転（ミキサー）が光り、熱・薄くは光らない**。持ち主の「逆順にしたら複数の属性が割合で出てくる」がそのまま起きた。
- **限界も見えた**: ホットプレート（熱）は鍋（熱）と同じ要素なので、「焼く」ではなく鍋と同じ「煮る」を返した。器は要素で道具を区別するので、**区別したい違い（平らな面・水の有無など）は要素として持たせる必要がある**。何を要素にするか（属性の選び方、持ち主の心配）が大事になる。
- 肉 × ジュースの逆引きは seed ごとにばらばら（肉はジュースにならないので、学習で決まっていない）。

## 残った疑問

- 重ね合わせ以上の組み合わせ（「圧力 + 熱だからこそ柔らかくなる」のような、どちらにもない答え）は、曲がる処理が要るはず（学び 14）
- 単語の格子を何枚も並べて、道具 × 単語 × 観点 を組み合わせる
