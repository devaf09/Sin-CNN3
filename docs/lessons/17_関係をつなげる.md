# 学び 17: 関係をつなげる — 出力の光をそのまま次の入力に

2026-10-27。実験17（experiments/exp17_chain.py）。

## 何をしたか

学び 16 の表し方（記号 = 周波数の波）では、入力と出力が同じ仕組みなので、出口の光をそのまま同じ器にもう一度通せる。
器には「1 回ぶんの対応」だけを教え、A を入れて出口の光を 5 回つなげて通した。

- 一本道: A → B, B → C, C → D, D → E, E → F
- 枝分かれ: A → B, C / B → D / C → E / D → F / E → G

器・学習は学び 16 と同じ（曲がる処理なし、列の間 64 画素、1500 回、3 seed）。

## 式の予想

曲がる処理のない光の器は重ね合わせが成り立つ（学び 09）。だから、

- 一本道: 回ごとに次の記号へ進む。答えに入る光は、1 回目の割合 p の回数乗（p^回）に減る。
- 枝分かれ: 1 回目は B と C の光の重ね合わせ。2 回目は「B の行き先 + C の行き先」= D と E が同時に光る。

## 結果

![関係をつなげる](../images/exp17_chain.png)

| | 1 回目 | 2 回目 | 3 回目 | 4 回目 | 5 回目 |
|---|---|---|---|---|---|
| 一本道（3 seed すべて） | B ○ | C ○ | D ○ | E ○ | F ○ |
| 答えに入った光（seed 0） | 0.93 | 0.88 | 0.81 | 0.75 | 0.70 |
| 式 0.93^回 | 0.93 | 0.86 | 0.80 | 0.75 | 0.70 |
| 枝分かれ（3 seed すべて） | B, C ○ | D, E ○ | F, G ○ | （教えていない） | |
| 答えに入った光（seed 0） | 0.92 | 0.87 | 0.81 | | |

## 分かったこと

- **関係をつなげてたどれた**。教えたのは 1 回ぶんの対応だけなのに、光を 5 回通すと A → B → C → D → E → F と進んだ（3 seed とも全部当たり）。
- **枝分かれは、重ね合わせのまま同時に進む**。B と C を同時に考え、その先の D と E を同時に出す。光の重ね合わせが「いくつもの道を同時にたどる」働きをする。
- 光は 1 回ごとに約 7% 減り、式 0.93^回 とほぼ一致した。5 回で 70% が残る。
- 教えていない先（G の先）では、光はでたらめな所へ行く（4 回目以降）。

## 残った疑問・次の一手

- 関係の数を増やすと、何組まで 1 つの器に入るか（容量）
- 枝分かれが多いと、光が薄く分かれていく。曲がる処理（明るい所だけ残す）で「強い道だけを残す」ことができるか（持ち主の「明るさが曲がる処理」の使い道の候補）
- 第 2 段階（ずらし）とつなげる: 文脈によって、たどる道を変える
