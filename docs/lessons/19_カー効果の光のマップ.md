# 学び 19: カー効果は光をどう動かして「どちらか片方だけ」を解いているか

2026-10-27。実験19（experiments/exp19_kerr_maps.py）。

## 何をしたか

学び 14 の器（色を分けた「どちらか片方だけ」、カー効果 γ = 2）を seed 0 で学習し直し、4 通りの入力（なし・A だけ・B だけ・A と B）を通した光の 2 次元マップと、右端の窓の明るさを記録した。
同じ学習済みの格子で、**カー効果だけを切った**場合も並べた。

## 結果

![カー効果あり・なしの光の 2 次元マップと窓の明るさ](../images/exp19_kerr_maps.png)

| 入力 | 正しい答え | カー効果あり（窓 0, 窓 1） | 同じ格子でカー効果を切る |
|---|---|---|---|
| なし（参照だけ） | 0 | **0.86**, 0.01 | 0.21, 0.06 |
| A だけ | 1 | 0.01, **2.22** | 0.46, 0.64 |
| B だけ | 1 | 0.01, **2.20** | 0.39, 0.77 |
| A と B | 0 | **5.12**, 0.04 | 0.65, 1.36（×） |

試験の正解率: カー効果あり 100%、同じ格子でカー効果を切ると 75.7%（曲がる処理なしの上限 75% とほぼ同じ）。

## 分かったこと

- **カー効果を切ると、同じ格子が 75.7% に落ちる**。答えを決めているのは格子だけではなく、カー効果そのもの。
- カー効果ありでは、光が「どちらの窓か」にはっきり分かれる（はずれの窓は 0.01 程度）。カー効果なしでは、どの入力でも両方の窓に光が出て、はっきりしない。
- 入れた光の量（なし < 片方 < 両方）によって、光の行き先が 窓 0 → 窓 1 → 窓 0 と行ったり来たりする。**明るさが増えると、光の向きが回っていく**ような振る舞い。明るさを「しきい値」で切るのではなく、明るさに応じて行き先が回るので、「両方ある」ときに元の窓へ戻せる。
- **見立ての修正**: 学び 14 では「ある色の通り道を、ほかの色の明るさで曲げ合う」と書いたが、光の 2 次元マップには、はっきりした「通り道」は見えなかった。列の間 64 画素の格子では、光は 1 列目から全体に散らばり（すりガラスを何枚も通したような、まだらな模様）、最後の列でまとまる。カー効果は、このまだらな模様そのものを明るさに応じて組み替え、最後にまとまる場所を変えていると考えられる（未確認）。
- 光の量は、両方あるときに窓 0 へ 5.1（入れた光の多くが 1 つの窓に集まる）。

## 残った疑問

- 明るさを少しずつ変えたとき、行き先がどう回るか（明るさ → 行き先の曲線）
- まだらな模様の器は、どれだけの「明るさの違い」を見分けられるか
