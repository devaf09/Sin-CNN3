# 学び 02: norm の 3 通り、sin の符号、振幅と位相の読み方

2026-10-27。実験02（experiments/exp02_norm_sin.py）。

## 何をしたか

長さ 8 の 3 つの波を、numpy・torch の fft に norm の 3 通りで通し、素朴な和（学び 01）に係数を掛けた予想と比べた。

1. cos(2π·n/8)（学び 01 と同じ）
2. sin(2π·n/8)
3. 2·cos(2π·2n/8 + π/3)（振幅 2・周波数 2・位相 π/3 = 60° を載せた波）

あわせて、ifft で元に戻るか、エネルギー（値の 2 乗の和）が保たれるか（パーセバルの等式）を見た。

## なぜか

学び 01 で、cos の山の高さが 4（= N/2）になるのは norm="backward" の約束だから、と分かった。前のプロジェクトは回折で "backward"、レンズで "ortho" を使っていたので、約束ごとに数字がどう変わるかを知っておく。また、波に情報を載せて読み出す（M1）には、振幅と位相が FFT のどこにどう出るかを知る必要がある。

## 使った関数と引数

| 引数 | 意味 |
|---|---|
| `norm="backward"`（既定） | fft では割らない。ifft で 1/N を割る |
| `norm="ortho"` | fft でも ifft でも 1/√N を割る（行き帰りで同じ） |
| `norm="forward"` | fft で 1/N を割る。ifft では割らない |

## 結果

![3 つの波と、その FFT の実部・虚部](../images/exp02_norm_sin.png)

山の大きさ（式の予想どおり。素朴な和との差はどれも 10⁻¹⁴ 以下）:

| 信号 | backward | ortho | forward | 位相 |
|---|---|---|---|---|
| cos（k = 1, 7） | 4 | 1.414（= 4/√8） | 0.5（= 4/8） | 0°, 0° |
| sin（k = 1, 7） | 4 | 1.414 | 0.5 | **−90°, +90°** |
| 2·cos(… + 60°)（k = 2, 6） | 8 | 2.828 | 1 | **+60°, −60°** |
| エネルギーの比 Σ\|X\|² / Σ\|x\|² | 8（= N） | **1（保たれる）** | 0.125（= 1/N） | |

- 同じ norm で ifft すると、どれも元に戻った（差 4 × 10⁻¹⁶ 以下）。
- 違う norm で往復すると、元に戻らない。例: fft を "ortho"、ifft を "backward" にすると 0.354 倍（= 1/√8）、fft "backward" → ifft "forward" は 8 倍。

## 分かったこと

- **norm は「どこで割るか」の約束だけ**で、波の形・位相は変わらない。大きさが 1 倍・1/√N 倍・1/N 倍になるだけ。
- **"ortho" だけがエネルギーを保つ**（波の側と周波数の側で、2 乗の和が同じ）。光のレンズのように「光の量を変えない変換」を真似るなら "ortho" が自然。前のプロジェクトのレンズが "ortho" なのは、これに合っている。
- **行きと帰りで norm をそろえないと、大きさがずれる**。前のプロジェクトは、回折（"backward" の行き帰り）とレンズ・4f 系（"ortho" の行き帰り）がそれぞれの中でそろっていた（コードを読んだ範囲。動かしての確認はまだ）。
- **sin は虚部に出て、正の周波数で −、負の周波数で + になる**。sin = (右回りの針 − 左回りの針) / (2i) で、1/i = −i だから。
- **振幅と位相はそのまま読める**: A·cos(2π·k·n/N + φ) は、X[k] = A·(N/2)·e^(iφ)。大きさから振幅 A（8 ÷ 4 = 2）、向き（位相）から φ（60°）が読める。負の周波数の側は位相の符号が逆（−60°）。
  → **波に数を載せて読み出す（M1）の土台**: 1 本の周波数に、振幅と位相の 2 つの数を載せられる。
