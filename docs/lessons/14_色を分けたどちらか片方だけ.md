# 学び 14: 色を分けた「どちらか片方だけ」— 曲がる処理（カー効果）が表計算の壁を越えた

2026-10-27。実験14（experiments/exp14_xor_colors.py）。

## 何をしたか

学び 12 で、明るさで読むこと自体（2 乗）と干渉のおかげで、曲がる処理なしでも「どちらか片方だけ」が 83% まで届いてしまい、曲がる処理そのものの効果が見えなかった。
そこで、A・B・参照の光を**別々の色**（互いに干渉しない光）にした。こうすると、曲がる処理なしでは窓の明るさが A と B の足し算になり、上限は本当に 75% になる。

- 3 色の光を、同じ格子・同じ回折に別々に通す（色ごとの違いは今回は無視）。窓では 3 色の明るさを足して読む。
- 曲がる処理は **3 色の明るさの合計** で効く（色をまたいで効く）: 飽和 u/√(1 + I/s)（s = 0.3・1・3）、カー効果 u·e^(iγI)（γ = 0.5・2）。
- 器・学習は学び 12 の器を直した版（列の間 64 画素）。訓練 400・試験 400、400 回、3 seed。比較相手: 小さなニューラルネットワーク、偶然 50%、上限 75%。

## 結果

![色を分けた「どちらか片方だけ」](../images/exp14_xor_colors.png)

| 曲がる処理 | 試験（3 seed の平均） | 各 seed | 1 seed の時間 |
|---|---|---|---|
| なし | 48.7 ± 3.0 | 53.0, 43.0, 50.2 | 62 秒 |
| 飽和 s = 0.3（強い） | 82.8 ± 8.6 | **100.0**, 73.8, 74.5 | 204 秒 |
| 飽和 s = 1 | 66.8 ± 5.4 | 72.0, 72.3, 56.0 | 199 秒 |
| 飽和 s = 3（弱い） | 61.3 ± 3.2 | 57.0, 67.5, 59.5 | 206 秒 |
| **カー効果 γ = 0.5** | **100.0** | 100, 100, 100 | 195 秒 |
| **カー効果 γ = 2** | **100.0** | 100, 100, 100 | 188 秒 |
| 小さなニューラルネットワーク | 100.0 | 100, 100, 100 | 1 秒未満 |

## 分かったこと

- **カー効果（明るいほど遅れる、色をまたいで効く）を入れた光の格子は、「どちらか片方だけ」を 3 seed とも 100% 解いた**。曲がる処理なしの上限 75% をはっきり越え、小さなニューラルネットワークと並んだ。**表計算（線形）では解けない課題を、光の曲がる処理で解けた**最初の結果。
- しくみの見立て（未確認）: カー効果は、ある色の光の通り道を、ほかの色の明るさで曲げる（光ファイバーの「相互位相変調」と同じ）。A と B が両方あると、互いの通り道を曲げ合って、どちらの光も答え 1 の窓から外れる。片方だけなら曲げられずに答え 1 の窓へ届く。
- 飽和は、強いほど良いが不安定（s = 0.3 で 100% の seed もあれば 74% の seed もある）。
- 曲がる処理なしは 48.7%（上限 75% にも届かない）。学び 12 と同じく、曲がる処理なしの器は学習が谷に落ちやすい。
- 学び 12（同じ色）ではカー効果が悪かった（56%）のに、色を分けると 100%。同じ色だと、干渉の揺れ（でたらめな位相）がカー効果の効き方を毎回変えてしまうためと考えられる（未確認）。
- 代わりに、計算は 3 倍（色ごとに通す）、曲がる処理ありは 1 seed 約 3 分（なしの約 3 倍）。
