# 学び 56: 語板を広げる — まれな語・動詞の語板・名詞 → 動詞 → 名詞（実験56）

2026-10-28。実験56（experiments/exp56_goban_grow.py）、部品 src/goban_batch.py（語板をまとめて学習・評価する）。

## 目的

実験55 で、会話データから名詞 400 語の語板を作れた。次の一歩として 3 つを確かめる。

- **A. まれな語**: 会話に少ししか出ない語（401〜1200 番目の名詞、学習用の出現 52〜154 回）は、数えた表がまばらになる。
  実験51 の「知らない物は近い語板を写して学び始める」が、本物の会話で効くか。
- **B. 動詞の語板**: 動詞 1 語 = 1 枚。観点 = 「を・が・で・に」の名詞（例: 食べる の「を」→ ラーメン・パン）。実験55 の表を裏返して作る（300 語）。
- **C. たどる**: 名詞の語板 →（を）→ 動詞の明るさ → 2 乗して組み直す（実験50）→ 動詞の語板 →（で・が）→ 名詞。

## 途中で見つけたこと: 光の量を保つ器の上限

動詞の語板を最初に作ったとき、交差エントロピーが 2.14 ビットで、**動詞を見ない（観点ごとの割合だけ）2.00 より悪かった**。
調べると、動詞の観点の値のうち、上位 47 個以外の名詞（「その他」）が平均 81% を占めていた。語板は「その他」に 33〜35% しか光を送れていなかった。

理由は、器が光の量を保つ（ユニタリ）こと。4 つの観点の入口の波は直交していて、器を通っても直交したまま。
同じ 1 つの出口 e に届く明るさを、4 つの入口について足すと、

Σ_観点 |<e, U u_観点>|² ≤ |e|² = 1

になる。**4 つの観点がすべて 81% を同じ出口に送ることはできない**（平均 25% 程度が上限）。
実験41 で「モードを増やすと答えに届く光が減る」と同じ理由で、器の大切な性質。

そこで「その他」を観点ごとに別の出口にした（出口 = 共通の 47 個 + 観点ごとの「その他」）。すると動詞の語板は 1.51 ビットになり、表（1.47）にほぼ並んだ。
名詞の語板も良くなった（実験55 の 2.69 → 2.57、表 2.54）。

**教訓: 光の器では、違う入口から同じ答えを大量に出したいときは、出口を分ける**。

## 結果（3 seed）

![実験56](../images/exp56_goban_grow.png)

### A. まれな名詞（交差エントロピー、低いほど良い）

| 作り方 | ビット |
|---|---|
| 名詞を見ない | 3.74 |
| 数えた表（+0.5 で平らに） | 3.02 |
| 語板 まっさら 100 回 | 3.03 |
| 語板 近い語板を写すだけ（学習なし） | 3.19〜3.21 |
| 語板 まっさら 600 回 | 2.77〜2.78 |
| **語板 近い語板を写して 100 回** | **2.70〜2.71** |
| 表を観点の割合へ寄せて平らに（k = 2 / 5） | 2.61 / **2.55** |

- **近い語板を写して 100 回は、まっさら 600 回より良く、6 分の 1 の学習で済む**（実験51 の受け継ぎが、本物の会話でも効いた）。
- 素朴な表（+0.5）には勝った。**ただし、表を「観点ごとの割合」へ寄せて平らにする（数の少ない語ほど全体の割合に寄せる、昔からある平滑化）と、表の方が良い（2.55）**。
  持ち主に「まれな語では表に勝った」と途中で伝えたが、弱い比べ相手に対してだった。訂正。
- 写した「近い語板」は、意味が近いとは限らない（連休 → 休み、練習 → 仕事 は近いが、傘 → 金、壁 → 心 は遠い）。近さを、表の 5 観点の形の似方だけで決めているため。

### B. 動詞の語板

| 方法 | ビット | 上位 1 |
|---|---|---|
| 動詞を見ない | 2.00 | 0.77 |
| **語板（「その他」を観点ごとに分けた）** | **1.51** | **0.77** |
| 数えた表 | 1.47 | 0.77 |
| 表を平らに（k = 10） | 1.41 | 0.77 |

### C. 名詞 → 動詞 → 名詞とたどる（seed 0）

| 名詞 | 「を」の動詞（上位 3） | → その動詞を「で」する名詞 | → その動詞を「が」する名詞 |
|---|---|---|---|
| ラーメン | 食べる・作る・調べる | 家・御店・一人・生・近く | 子供・人・味 |
| 映画 | 見る・作る・取る | テレビ・目・映画館・ニュース | 人・顔・子供 |
| 服 | 着る・買う・見る | 家・部屋・一人・スーパー | 人・子供・者 |
| 本 | 読む・買う・探す | 無料・スマホ・ネット | 心・子供・人 |
| 料理 | 作る・食べる・為る | 家・御自分・一人・御店・自宅 | 音・子供・人 |

「ラーメンを食べる → 家で・お店で」「映画を見る → テレビで・映画館で」「服を買う → スーパーで」と、2 段たどって意味の通る答えが出た。
「が」の観点は「子供・人」が多く、まだ一般的すぎる（会話では主語を言わないことが多い）。

## なぜそうなったか

- 語板は「表をまねる」ので、よく出る語では表に近づき、越えない。まれな語では、表がまばらで、語板も同じまばらな表をまねるので、
  語板ならではの強さは「近い語板から始めると少ない学習で済む」点に出た。平滑化そのものは、表を全体の割合へ寄せる方が上手。
- たどる処理は、実験50 の「2 乗して組み直す」で、名詞 → 動詞の段で候補を絞ってから次の語板へ渡している。

## 分かったこと

- **語板は数を増やせる**（名詞 1200 語 + 動詞 300 語を、CPU で 1 seed 約 50 秒）。動詞にも語板を作れ、名詞 → 動詞 → 名詞とたどれる。
- **光の量を保つ器では、違う入口から同じ出口へ大量に光を集められない**。出口を分けることで解決した。大規模にするときの設計の大事な決まりになる。
- まれな語は、近い語板を写して始めると学習が 6 分の 1 で済む。ただし平滑化の上手さでは、昔からの表の方法に負ける。
  語板の強み（逆引き・掛け算・融合・たどる）と、表の強み（平滑化）を組み合わせる形を考える必要がある。

## 残った疑問

- 近い語板の選び方を、意味の近さ（逆引きの明るさの似方、文脈）で行う。
- 語板の学習に、表を観点の割合へ寄せる平滑化を入れる（目標の表を平らにしてから学ぶ）と、表に追いつくか。
- 「が」の観点を、主語を省いた会話でどう扱うか。
