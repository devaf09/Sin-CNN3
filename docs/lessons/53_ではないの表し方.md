# 学び 53: 「〜ではない」の表し方（実験53）

2026-10-28。実験53（experiments/exp53_negation.py）。学び 51（実験52）の続き。

## 目的

持ち主（2026-10-28）:

> 〇〇ではない、を表す方法はいくつか考えてるんだけど、結構難しい気がする。問題は範囲の広さなので、0 − 特徴や属性でマイナス差分がいいのかなぁ。

文の中の「赤くない」「果物ではない」を、周りの語の属性の掛け算（実験52）にどう入れるか。

## 理由（なぜ難しいか）

「赤い」は 1 つの値（赤）を光らせれば表せる。「赤くない」は、緑・紫・黄…の全部を含む（範囲が広い）。
光らせる値を 1 つに決められないので、肯定と同じ形では表せない。考えられる形は次の 4 つ。

| 扱い方 | 式（候補 c の点数に掛ける・足すもの） | 予想 |
|---|---|---|
| 割り算（式のマイナスのべき） | p^{−1}（p = c がその値を持つ割合） | p がほぼ 0 の物で点数が爆発する。「赤ではない物」の中でも、たまたま赤が 0 の物が勝ってしまう |
| 0 − 特徴（持ち主の案） | 足し算の点数から p を引く（0 未満は 0） | 範囲の広さに関係なく効く。ただし足し算なので確信度は低め |
| 1 − p（補い） | (1 − p) を掛ける = 赤に行かなかった残りの光の割合 | 範囲がどれだけ広くても 0〜1 に収まる。掛け算の中で使える |
| 比べ: 無視 / 読み落とす | 否定を使わない / 否定を見落として肯定として掛ける | 否定が答えを決める文で外れる |

「1 − p」は「0 − 特徴」と同じ考えを、明るさの全体（1）を基準にして書いたもの。光では、ビームスプリッタのもう片方の出口や、
全体の明るさから特徴の明るさを引く差動の検出（学び 44）で作れる。

## 方法

実験52 と同じ 7 物のグレイン（3 seed）。否定を含む文 5 つ（○○ の答え）:
赤くない 丸い 甘い ○○ を かじった（リンゴ。イチゴ・トマトはほぼ赤だけ）／甘くない 細長い ○○ を 焼いた（ナス）／果物ではない 赤い ○○（トマト）／
加熱しない 緑の ○○ を サラダ に（キュウリ）／苦くない 緑の 細長い ○○ を 焼いた（キュウリ。ピーマンは苦い）。

## 結果

![実験53](../images/exp53_negation.png)

| 扱い方 | 正解（5 文 × 3 seed） | 正しい物の割合（確信度） |
|---|---|---|
| 無視 | 9 / 15 | 果物ではない・苦くない の文で外れる |
| 読み落とす | 4 / 15 | 否定と逆の物（甘くない → バナナ 83〜97%）に強く引っ張られる |
| 割り算 | 7 / 15 | 外れるときは、ほぼ関係ない物（果物ではない 赤い → ナス・ピーマン・キュウリ）が勝つ |
| **0 − 特徴（持ち主の案）** | **15 / 15** | 24〜40%（果物ではない 赤い だけ 93〜96%） |
| **1 − p（補い）** | **15 / 15** | **54〜95%** |

## なぜそうなったか

- 割り算は、p が 0 に近い物ほど点数が大きくなる。「果物ではない」で果物の割合がたまたま 0 の物（ナス・ピーマン）が、
  「赤い」に合わなくても、割り算の爆発で勝ってしまう。範囲が広い否定ほど、p ≈ 0 の物が多いので不安定。
- 0 − 特徴は、引く量が「その値を持つ割合」なので、範囲の広さに関係なく、その値を持たない物は 0 しか引かれない。だから全問正解した。
  ただ、足し算の点数なので、候補どうしの差が小さく、確信度は低め（学び 51 の足し算と同じ）。
- 1 − p は、同じ「持っている分だけ減らす」を、掛け算の中で行う。合わない候補は掛け算で 0 に近づくので、確信度も高い。

## 分かったこと

- **「〜ではない」は、「その値に行かなかった残りの光の割合（1 − p）」を掛ければ、範囲の広さに関係なく表せる**。持ち主の「0 − 特徴」の考え方は正しく、
  基準を 0 ではなく「全体の明るさ 1」にすると、掛け算の中でそのまま使える。
- 光では、値の明るさと、それ以外の明るさ（残りの光）を別々の出口で受ければよい。逆引き・融合・差分と同じく、明るさで行うのが確実。
- 割り算（マイナスのべき）は、範囲の広い否定では使えない。

## 残った疑問

- 「少しだけ赤い」「あまり甘くない」のような程度の否定は、(1 − p)^w の重み w で表せるか。
- 二重否定（「赤くないわけではない」）。
- 否定の手がかりも、手で作った表から出している。会話データから「ない」「ではない」を含む文を集めて、語のグレインに学ばせる必要がある。
