# 学び 20: 強い道だけを残せるか — 重なった 2 つの記号から、明るい方だけを通す

2026-10-27。実験20（experiments/exp20_winner.py）。

## 何をしたか

学び 17 で、枝分かれは重ね合わせのまま同時に進み、光は薄く分かれていった。考えるときは、強い候補だけを残して弱い候補を消したい。
記号（周波数の波、6 個）を 2 つ重ねた光（明るさの比は 勝者 55〜90% : 敗者、位相はでたらめ）を入れ、勝者の記号だけが出口で光るように学習させた。

- 曲がる処理（1 色）: なし / カー効果（γ = 30・100・300）/ 飽和（s = 0.01・0.003。小さいほど強く曲がる）
- 器は学び 16 と同じ。訓練 400・試験 400、600 回、3 seed。
- 指標: **鋭さの増え方** = 出口での勝者の割合 − 入口での勝者の割合。

## 式の予想

曲がる処理なし（線形）では、出口の勝者と敗者の明るさの比は、入口の比を写すことしかできない（「どちらが明るいか」で態度を変えられない）。だから鋭さの増え方は 0 点以下。曲がる処理があれば、0 点を越えられる可能性がある。

## 結果

![強い道だけを残せるか](../images/exp20_winner.png)

| 曲がる処理 | 鋭さの増え方（点、3 seed） | 勝者が一番明るい |
|---|---|---|
| なし | −0.1 ± 0.0 | 100% |
| カー効果 γ = 30 | −21.7 ± 0.7 | 17.8%（学習が崩れた） |
| カー効果 γ = 100 | −21.8 ± 1.3 | 17.9%（学習が崩れた） |
| カー効果 γ = 300 | 計算が発散 | − |
| 飽和 s = 0.01 | **+2.3 ± 0.4** | 99.9% |
| 飽和 s = 0.003 | **+4.2 ± 0.3** | 99.8% |

## 分かったこと

- **曲がる処理なしは、式どおり 0 点**（入口の比をそのまま写す）。
- **飽和（明るいほど通りにくい）を入れると、3 seed とも 0 点を越えた**（+2.3 点、強くすると +4.2 点）。明るい方を少し残し、暗い方を少し削る、という「強い道を残す」向きの働きは出た。ただし量はまだ小さい（勝者 70% の入力が、出口で 74% になる程度）。
- **カー効果は、1 色の光では学習そのものが崩れた**（学び 12 と同じ）。2 つの記号の位相がでたらめなので、カー効果の効き方が毎回変わる。学び 14 で効いたのは、色を分けて干渉をなくしたとき。
- 飽和の強さを上げるほど鋭くなるので、もっと強い飽和・何段も通す（学び 17 のようにつなげる）と、さらに鋭くできるかもしれない。

## 残った疑問・次の一手

- 色を分けた（または位相をそろえた）入力なら、カー効果で強く鋭くできるか
