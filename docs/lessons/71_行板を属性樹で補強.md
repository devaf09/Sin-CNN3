# 学び 71: 行板を属性樹で補強する — 木の道筋の目印で、章をまたぐ行の連想が 2〜3 倍に（実験71）

2026-10-29。実験71（experiments/exp71_tree_line_boards.py）。持ち主「実験70 の連想の方法は的確。次は行板を属性樹で補強できないか考えたい」。

## 方法

- 名詞の語板 2 万語（実験59）で属性樹を作った（実験65 の考え: 共通の度合いの大きい属性で枝分かれ、深さ 4、1 つの節から最大 6 本）。節は 1429 個。
  節の仲間 = 根からその節までの属性を全部持つ語。2 万語のうち 8000 語ほどが根より深い節に入り、1.2 万語は根のまま（どの枝の属性も持たない）。
- 2 つの補強を、実験70 と同じ問題（青空文庫 60 作品、章をまたぐ 2 行、つなぐ名詞は取り除く、1200 問、候補 約 1100 行）で比べた。
  1. **木でならした行板**: 各名詞の語板に、いちばん深い節の融合した板を混ぜる（α = 0.3・0.5）
  2. **木の道筋の目印**: 行の名詞が通る節に印を付け（深い節ほど重く = 2^深さ）、行どうしの印の重なりを測る

## 結果

| 探し方 | 1 位に入る | 上位 5 に入る | MRR |
|---|---|---|---|
| でたらめ | 0.4% | 0.8% | 0.012 |
| 行板（実験70） | 1.3% | 3.1% | 0.029 |
| 木でならした行板（α = 0.3 / 0.5） | 1.0% / 1.1% | 3.6% / 3.0% | 0.028 / 0.027 |
| **木の道筋の目印** | **4.1%** | **6.3%** | **0.057** |
| 共通の名詞の数 | 1.7% | 3.7% | 0.034 |
| 行板 + 共通の名詞（実験70） | 1.4% | 4.4% | 0.034 |
| ならした行板 + 道筋 + 共通の名詞（順位を足す） | 1.5% | 3.3% | 0.030 |

## 分かったこと・考察

- **木の道筋の目印が、いちばん良かった**: 1 位は行板の 3 倍（1.3% → 4.1%）、上位 5 は 2 倍（3.1% → 6.3%）。
  「深い節（細かい仲間）を一緒に通る語がある行どうしは関係が深い」という持ち主の考え（属性樹の内訳）が、連想に効いた。
- **木でならした行板は効かなかった**。語板に仲間の平均を混ぜると、行どうしの違いがかえってぼやける（どの行も似た模様になる）。
- **順位を足して組み合わせると、かえって悪くなった**。弱い方法を足すと、強い方法（道筋）が薄まる。組み合わせるなら重みを付ける必要がある。
- なぜ道筋が効くか: 行板の明るさの模様は、多い属性（を 為る・が 有る）に引っ張られて、どの行も似てしまう。
  道筋の目印は「どの細かい仲間か」だけを見るので、多い属性の影響を受けにくい（深い節ほど重くしているため）。
- 光でやる形: 各節を 1 本の出口（印）にした「節の板」に、行の名詞の光を通すと、通った節が光る。その光の模様どうしの重なりを測れば、道筋の目印と同じになる。

## 限界と次の一歩

- 2 万語のうち 1.2 万語は根のまま（どの節にも入らない）。木を広げる（枝の数・属性の選び方）と、もっと多くの語が目印を持てる。
- 正解の決め方（2 行にだけ出る名詞）は厳しいまま。
- 次: 道筋の目印と、動詞の語板・前後の行を組み合わせる（重み付きで）。目印を光の「節の板」で作る。
